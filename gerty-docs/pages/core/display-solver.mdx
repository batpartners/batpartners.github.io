## 사용 순서

<Steps>

1. **GERTY Solver** 에 [GERTY Core](/core/gerty-core/) 의 **GERTY Solver** 출력을 연결한다.
2. **Simulation Pop-up** 을 켜면 시뮬레이션 컨트롤 창이 열린다. 이 창에서 Rhino 뷰포트의 로봇 동작을 재생해 본다.
3. **Tool Center Plane** 출력으로 현재 TCP 평면을 다른 작업에 쓴다.

</Steps>
