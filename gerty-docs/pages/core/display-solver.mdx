Display Solver 는 정의된 로봇 모션을 Rhino 뷰포트에서 시뮬레이션하고 시각화하여 전체 작업 과정을 확인할 수 있는 컴포넌트이다. GERTY Core 의 연산 결과를 받아 시뮬레이션 컨트롤 창에서 재생하며, 현재 TCP 평면을 출력한다.

## 사용 순서

<Steps>

1. **GERTY Solver** 에 [GERTY Core](/core/gerty-core/) 의 **GERTY Solver** 출력을 연결한다.
2. **Simulation** 탭의 **Simulation Window** 를 켜면 시뮬레이션 컨트롤 창이 열린다. 이 창에서 Rhino 뷰포트의 로봇 동작을 재생해 본다.
3. 필요하면 **Current TCP** 출력으로 현재 TCP 평면을 다른 작업에 쓴다.

</Steps>
