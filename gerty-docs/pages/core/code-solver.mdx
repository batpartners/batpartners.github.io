정의된 로봇 모션으로부터 RAPID 프로그램을 생성하고, 네트워크에 연결된 ABB 컨트롤러로 전송·업로드하는 컴포넌트이다.

이 페이지는 우클릭 메뉴의 기본 모드인 <strong>[Single-Task (Standard)]</strong> 를 설명한다. 하나의 RAPID 태스크로 프로그램을 내보낸다. 소켓 통신을 쓰는 멀티태스크 프로그램은 <strong>[Multi-Task (Option 623-1)]</strong> 모드에서 만든다.

## 사용 순서

<Steps>

1. **GERTY Code** 에 [GERTY Core](/core/gerty-core/) 의 **GERTY Code** 출력을 연결한다. 컨트롤러에 바로 올리려면 **ABB Controller** 에 [Scan ABB Controller](/controller-utils/scanabbcontroller/) 출력을 연결한다.
2. **Program Settings** 탭에서 **Program Folder** 와 **Program Name** 을 정한다.
3. **Export** 탭에서 **Export** 를 눌러 RAPID 코드를 생성한다. **Auto Load** 를 켜 두면 생성 후 연결된 컨트롤러에 자동으로 로드한다. 결과는 **Export Log** 에 표시된다.
4. **Open in Editor** 로 생성된 코드를 열어 확인한다.

</Steps>

## 주의 사항

<Aside type="tip">
  **Open in Editor** 는 생성된 코드를 VSCode 로 엽니다. VSCode 가 설치되어 있지 않으면 메모장으로 엽니다.
</Aside>

<Aside type="note">
  저장 위치는 우클릭 메뉴의 **Select a Local directory…** 로 바꾸고, **Open Local directory** 로 열 수 있습니다. 기본 위치는 `Documents\GERTY\RobotPrograms` 입니다.
</Aside>
