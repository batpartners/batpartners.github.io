## 사용 순서

<Steps>

1. **GERTY Robot** 에 [ABB Robots](/robot-tool/abbrobot/) 의 **GERTY Robot** 출력을 연결한다.
2. **Instructions** 에 인스트럭션 리스트를 연결한다. 리스트 순서가 그대로 로봇 실행 순서가 된다. 서브 프로시저를 쓰면 **SubProc.** 도 연결한다.
3. **GERTY Solver** 출력을 [Display Solver](/core/display-solver/)·[Analysis Deconstructor](/core/analysis/) 에, **GERTY Code** 출력을 [Code Solver](/core/code-solver/) 에 연결한다.

</Steps>

## 주의 사항

<Aside type="caution">
  **Instructions** 의 리스트 순서가 로봇 실행 순서와 직접 대응하므로, 의도한 모션 순서대로 정렬해야 한다.
</Aside>
