GERTY Core 는 정의된 로봇 셋업(Robot Setup)과 인스트럭션으로부터 로봇 동작을 연산하는 컴포넌트이다. 시뮬레이션과 분석에 쓰는 **GERTY Solver** 와 RAPID 코드 생성에 쓰는 **GERTY Code** 를 출력하며, 이는 Display Solver 와 Code Solver 실행에 필요한 기초 데이터이다.

## 사용 순서

<Steps>

1. **Robot Setup** 에 [ABB Robots](/robot-tool/abbrobot/) 의 **Robot Setup** 출력을 연결한다.
2. **Instructions** 에 인스트럭션 리스트를 연결한다. 리스트 순서가 그대로 로봇 실행 순서가 된다. 서브 프로시저를 쓰면 **SubProc** 도 연결한다.
3. 필요하면 **GERTY Core** 탭에서 **Config Option (Cfx = 1)** 과 **Ignore Errors** 를 정한다.
4. **GERTY Solver** 출력을 [Display Solver](/core/display-solver/)·[Analysis Deconstructor](/core/analysis/) 에, **GERTY Code** 출력을 [Code Solver](/core/code-solver/) 에 연결한다.

</Steps>

## 주의 사항

<Aside type="caution">
  **Instructions** 의 리스트 순서가 로봇 실행 순서와 직접 대응하므로, 의도한 모션 순서대로 정렬해야 합니다.
</Aside>

<Aside type="caution">
  **Ignore Errors** 를 켜면 동작 오류가 검출되어도 코드를 출력합니다. 로봇에서 실행하기 전에 RAPID 코드와 운용 절차를 반드시 확인하십시오. 기본값(꺼짐)에서는 오류가 검출되면 코드 생성을 중단합니다.
</Aside>
