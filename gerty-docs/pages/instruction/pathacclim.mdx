## 사용 순서

<Steps>

1. **Acceleration Params** 탭의 **AccLim** / **DecelLim** 로 TCP 가속·감속 제한을 켠다.
2. 켠 항목의 최대값을 **AccMax(m/s²)** / **DecelMax(m/s²)** 에 정한다.
3. **Instructions** 출력을 인스트럭션 리스트의 실행할 위치에 넣어 [GERTY Core](/core/gerty-core/) 의 **Instructions** 입력에 연결한다.

</Steps>
