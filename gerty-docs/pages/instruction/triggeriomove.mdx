## 사용 순서

<Steps>

1. **RobTarget** 에 [RobTarget](/datatype/robtarget/) 또는 [Positioner RobTarget](/datatype/positioner-robtarget/) 출력을 연결한다.
2. **TriggIOs** 에 [TriggIOs](/datatype/triggios/) 출력을 연결한다. 트리거 하나하나는 [IOEvent](/datatype/iodevent/) 로 정의한다.
3. **TriggIOs Move** 탭에서 모션 유형·속도·Zone 을 고른다.
4. **Instructions** 출력을 인스트럭션 리스트의 실행할 위치에 넣어 [GERTY Core](/core/gerty-core/) 의 **Instructions** 입력에 연결한다.

</Steps>

## 주의 사항

<Aside type="note">
  MoveL 이면 `TriggLIOs`, MoveJ 이면 `TriggJIOs` 인스트럭션이 만들어집니다.
</Aside>
