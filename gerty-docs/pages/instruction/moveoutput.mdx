## 사용 순서

<Steps>

1. **RobTargets** 에 [RobTarget](/datatype/robtarget/) 또는 [Positioner RobTarget](/datatype/positioner-robtarget/) 출력을 연결한다.
2. **Signal** 에 출력 신호 이름을, **DO Value** 에 쓸 값을 연결한다.
3. **ABB MoveXO** 탭에서 모션 유형·속도·Zone 과 **MoveJ Start & End** / **Fine Start & End** 를 정한다.
4. **Instructions** 출력을 인스트럭션 리스트의 실행할 위치에 넣어 [GERTY Core](/core/gerty-core/) 의 **Instructions** 입력에 연결한다.

</Steps>

## 주의 사항

<Aside type="note">
  신호 유형에 따라 `MoveJDO` / `MoveLDO`(디지털), `MoveJGO` / `MoveLGO`(그룹), `MoveJAO` / `MoveLAO`(아날로그) 인스트럭션이 만들어집니다.
</Aside>
