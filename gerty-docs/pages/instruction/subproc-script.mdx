## 사용 순서

<Steps>

1. **Proc Code** 에 PROC 부터 ENDPROC 까지의 RAPID 코드를 연결한다.
2. **Call** 에 호출 문자열(예: `CustomProc 5, target1;`)을 호출하는 곳마다 하나씩 연결한다.
3. **Sub Proc.** 출력을 인스트럭션 리스트의 실행할 위치에 넣어 [GERTY Core](/core/gerty-core/) 의 **Instructions** 입력에 연결한다.

</Steps>

## 주의 사항

<Aside type="caution">
  **Call** 의 프로시저 이름과 인자는 **Proc Code** 의 PROC 선언과 맞아야 한다.
</Aside>
