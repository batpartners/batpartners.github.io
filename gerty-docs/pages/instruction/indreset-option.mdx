부가 축의 위치와 회전값을 초기화(<code>IndReset</code>)하는 컴포넌트이다. 모션 인스트럭션 실행 전 누적된 외부축 각도값 초기화에 주로 사용한다.

이 페이지는 기준 위치를 <strong>RobTarget</strong> 입력으로 받는 Positional Reference 형태를 설명한다.

## 사용 순서

<Steps>

1. **RobTarget** 에 기준 자세를 담은 [RobTarget](/datatype/robtarget/) 을 연결한다.
2. **MechUnit** 에 메카니컬 유닛 이름(예: STN1)을 쓰고, **Target Axis** 에서 대상 축을 고른다.
3. **Settings** 탭에서 **Direction Policy** 를 `Short` / `Fwd` / `Bwd` 중에서 고른다.
4. **Instructions** 출력을 인스트럭션 리스트의 실행할 위치에 넣어 [GERTY Core](/core/gerty-core/) 의 **Instructions** 입력에 연결한다.

</Steps>

## 주의 사항

<Aside type="tip">
  [IndRMove](/instruction/indrmove/) 로 독립 모드에 둔 축을 일반 모드로 되돌릴 때, 또는 모션 전에 누적된 외부축 각도를 초기화할 때 씁니다.
</Aside>

<Aside type="caution">
  **RobTarget** 과 **RefNum(°)** 은 함께 쓸 수 없습니다.
</Aside>
