ABB 이동 인스트럭션(`MoveL`, `MoveJ`)을 만드는 컴포넌트이다. 입력한 RobTarget 마다 이동 명령을 만들며, 모션 유형·속도·Zone 은 설정에서 한 번에 정한다. 첫 번째와 마지막 타겟만 `MoveJ` 나 `fine` Zone 으로 바꾸는 옵션도 있다.

## 사용 순서

<Steps>

1. **RobTargets** 에 [RobTarget](/datatype/robtarget/) 또는 [Positioner RobTarget](/datatype/positioner-robtarget-dynamic/) 출력을 연결한다.
2. **Move** 탭의 **Move** 에서 모션 유형·속도·Zone 을 고른다.
3. 첫·마지막 타겟만 `MoveJ` 로 하려면 **MoveJ Start End** 를, 첫·마지막 타겟에서 정확히 멈추려면 **Fine Start End** 를 켠다.
4. **Instruction** 출력을 인스트럭션 리스트의 실행할 위치에 넣어 [GERTY Core](/core/gerty-core/) 의 **Instructions** 입력에 연결한다.

</Steps>
