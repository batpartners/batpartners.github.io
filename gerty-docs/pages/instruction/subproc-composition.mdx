인스트럭션 리스트로 RAPID 서브 프로시저(SubProcedure) 블록을 만드는 컴포넌트이다. 블록은 **Name** 에 정한 이름의 PROC 으로 출력되며, 메인 루틴에서 이 이름으로 호출할 수 있다.

이 페이지는 우클릭 메뉴의 기본값인 **Composition Mode** 형태를 설명한다. RAPID 코드를 직접 쓰는 **Script Mode** 는 [Sub Procedure (Script)](/instruction/subproc-script/) 를 참고한다.

## 사용 순서

<Steps>

1. 프로시저에 담을 인스트럭션 리스트를 **Instructions** 에 연결한다.
2. **SubProcedure** 탭의 **Name** 에 프로시저 이름을 쓴다.
3. **SubProc** 출력을 인스트럭션 리스트의 실행할 위치에 넣어 [GERTY Core](/core/gerty-core/) 의 **Instructions** 입력에 연결한다.

</Steps>
