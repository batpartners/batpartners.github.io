## 사용 순서

<Steps>

1. **ABB Controller** 에 [Scan ABB Controller](/controller-utils/scanabbcontroller/) 의 출력을 연결한다.
2. **Mechanical Unit** 탭에서 **Update** 를 눌러 유닛 목록을 갱신하고, **Mechanical Unit** 에서 외부 메커니컬 유닛을 고른다.
3. **Joint Planes** 와 **Axis Name** 으로 캘리브레이션된 축 좌표계를 받는다. **Info** 와 **Warnings** 로 축 구성과 경고(미캘리브레이션·잠금 축 등)를 확인한다.

</Steps>

## 주의 사항

<Aside type="note">
  먼저 [ScanABBController](/controller-utils/scanabbcontroller/) 로 컨트롤러에 연결해 두어야 값을 가져온다.
</Aside>
