## 사용 순서

<Steps>

1. **ABB Controller** 탭의 **Controller Type** 에서 **Real**(실제 컨트롤러) 또는 **Virtual**(가상 컨트롤러)을 고르고 **Scan** 을 눌러 컨트롤러를 검색한다.
2. **Connect** 탭의 **Controller** 에서 연결할 컨트롤러를 고르고 **Connect** 를 켠다.
3. **Info** 탭에서 연결된 컨트롤러 정보를 확인한다.
4. **ABB Controller** 출력을 Controller Utils 컴포넌트와 [Code Solver](/core/code-solver/) 의 **ABB Controller** 입력에 연결한다.

</Steps>
