## 사용 순서

<Steps>

1. **SocketBundle** 에 [Code Solver (Option)](/core/code-solver-option/) 의 **SocketBundle** 출력을 연결한다.
2. **Connect** 탭에서 **Connect** 를 켜 컨트롤러에 소켓으로 연결한다.
3. 필요하면 **Queue/Timing** 탭에서 큐 상한·전송량·주기를 조정한다.
4. **Contorol** 탭의 **Send** 를 켜면 스트리밍이 시작되고, 끄면 전송이 멈추고 로봇이 일시 정지한다. 처음부터 다시 보내려면 **Reset** 을 누른다.
5. **Log/Status** 탭에서 통신 상태와 로그를 확인한다.

</Steps>

## 주의 사항

<Aside type="caution">
  **Reset** 을 누르면 로봇이 멈춘 뒤, 첫 패킷을 받으면 시작 위치부터 다시 움직인다.
</Aside>

<Aside type="tip">
  **Bundle Size** 는 기본 5, 최대 8 이하를 권장한다. **Interval(ms)** 을 줄이면 반응이 빨라지고, 늘리면 부하가 줄어든다.
</Aside>
