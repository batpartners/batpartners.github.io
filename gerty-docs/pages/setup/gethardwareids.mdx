기기 식별을 위해 로컬 머신의 하드웨어 기반 식별자(MAC 주소, 디스크 시리얼, BIOS/UUID, USB ID)를 수집하는 컴포넌트이다. 라이선스 신청에 필요한 기기 정보를 확인할 때 쓴다. 기기 식별자는 로컬에서 처리되며, 하드웨어 ID는 외부로 전송되거나 저장되지 않는다.

## 사용 순서

<Steps>

1. 캔버스에 컴포넌트를 놓으면 **MachineIDs**, **USBInfos**, **USBIDs** 로 이 PC 의 하드웨어 ID 가 나온다. 다시 읽으려면 **Actions** 탭의 **Refresh** 를 누른다.
2. 라이선스를 신청하려면 **Contact Support** 를 눌러 문의 페이지를 연다.

</Steps>

## 주의 사항

<Aside type="note">
  하드웨어 ID 는 로컬에서만 처리되며 외부로 전송되거나 저장되지 않습니다.
</Aside>
