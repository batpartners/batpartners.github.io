사용할 ABB 로봇을 정의하는 컴포넌트이다. ABB IRB 시리즈 카탈로그의 사전 정의된 제원에서 로봇 모델과 사양을 고르고, 베이스 평면·툴·포지셔너·주변 메시를 묶어 하나의 로봇 셋업(Robot Setup)으로 출력한다. 컴포넌트를 우클릭하여 <strong>[Show Joint Jog Params]</strong> 를 켜면 <strong>Robot Joint Jog</strong> / <strong>External Joint Jog</strong> 탭이 추가되어 로봇 관절축과 외부축을 직접 조작할 수 있다.

## 사용 순서

<Steps>

1. **ABB Robots** 탭의 **Robot Model** 에서 ABB 로봇 모델을, **Spec** 에서 가반하중·작업 반경 사양을 고른다.
2. **ToolData** 에 [ToolData](/datatype/tooldata/) 를 연결한다. 로봇 베이스가 WorldXY 가 아니면 **Base Plane** 도, 포지셔너를 쓰면 **Positioner** 에 [ABB Positioner](/robot-tool/positioner/) 를, 받침대 등 주변 형상이 있으면 **Pedestal** 도 연결한다.
3. 필요하면 **Robot Linear Jog** 탭에서 자세를 초기화(**Reset Pose**)하거나 TCP 를 World 축에 정렬(**Align Gumball**)하고, **Current TCP** 출력으로 현재 TCP 평면을 확인한다.
4. **Robot Setup** 출력을 [GERTY Core](/core/gerty-core/) 의 **Robot Setup** 입력에 연결한다.

</Steps>

## 주의 사항

<Aside type="note">
  **Robot Linear Jog** 탭의 **Config Option** 을 켜면 cfx = 1 로, 로봇 축 4·6 의 구성(Configuration)을 반전합니다. 끄면 cfx = 0(기본 구성)이며, 기본값은 꺼짐입니다.
</Aside>

<Aside type="tip">
  **Align Gumball** 은 TCP 를 현재 방향에 가장 가까운 World 좌표축(±X, ±Y, ±Z)과 평행하게 정렬합니다. ABB FlexPendant 조그의 Align 기능과 같습니다.
</Aside>
