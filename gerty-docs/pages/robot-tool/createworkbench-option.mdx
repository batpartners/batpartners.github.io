포지셔너 플랜지에 장착할 워크벤치(Workbench)와 작업물(Workpiece)을 정의하는 컴포넌트이다. 실제 작업대와 작업물 형상을 시뮬레이션에 반영하여 포지셔너 구동 중 발생할 수 있는 간섭을 검증하고 경로 시뮬레이션을 정밀하게 수행할 수 있다.

이 페이지는 컴포넌트를 우클릭하여 <strong>[Import Workbench]</strong> 를 선택했을 때를 설명한다. <strong>Export</strong> 로 저장해 둔 워크벤치를 <strong>WorkBench</strong> 탭의 <strong>Presets</strong> 에서 불러오므로 형상 메시 입력이 없다.

## 사용 순서

<Steps>

1. 컴포넌트를 우클릭하여 **Import Workbench** 를 선택한다.
2. **WorkBench** 탭의 **Presets** 에서 저장해 둔 워크벤치를 고른다.
3. **Base Plane** 에 포지셔너 플랜지에 닿는 워크벤치 하단 기준면을 연결한다. 상단 기준면을 바꾸려면 **Top Plane** 을 연결하고(연결하지 않으면 저장된 Top Plane 을 사용), 작업물이 있으면 **Workpieces** 도 연결한다.
4. 필요하면 **Name** 과 **Preview** 탭의 워크벤치·작업물 색상을 정한다.
5. **Workbench** 출력을 [ABB Positioner](/robot-tool/positioner/) 의 **Workbench** 입력에 연결한다.

</Steps>

## 주의 사항

<Aside type="tip">
  실제 작업대와 작업물 형상을 넣으면 포지셔너가 움직일 때 생기는 간섭을 시뮬레이션에서 미리 확인할 수 있습니다.
</Aside>

<Aside type="note">
  **Presets** 목록에는 Export 로 저장한 워크벤치가 나타납니다. 우클릭 메뉴의 **Open Workbench Folder** 로 저장 폴더(`Documents\GERTY\UserAssets\WorkBench`)를 열 수 있습니다.
</Aside>
