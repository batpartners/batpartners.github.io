## 사용 순서

<Steps>

1. **PositionerGeo** 에 포지셔너 링크 형상 메시를, **Joints** 에 베이스부터 플랜지까지의 기구학 평면 리스트를 연결하고 **Axis Type** 을 고른다.
2. 포지셔너 플랜지 평면이 WorldXY 가 아니면 **MountingPl** 을, 워크벤치를 달려면 **WorkBench** 에 [CreateWorkBench](/robot-tool/createworkbench/) 출력을 연결한다.
3. **Motion Settings** 탭에서 암 동작(**Enable Arm**)과 TCP 접근·정렬 방향을, **RAPID Setting** 탭에서 RobTarget 의 외부축 배열에 쓸 **Arm / Plate Joint Index** 를 정한다.
4. **Positioner** 출력을 [ABB Robots](/robot-tool/abbrobot/) 와 [Positioner RobTarget](/datatype/positioner-robtarget/) 의 **Positioner** 입력에 연결한다.

</Steps>

## 주의 사항

<Aside type="caution">
  **Arm Joint Index** 와 **Plate Joint Index** 는 다른 외부축 인덱스와 겹치면 안 된다. 예: Arm = 2, Plate = 3 → ExtJoint [9E9, arm, plate, 9E9, 9E9, 9E9].
</Aside>

<Aside type="note">
  **Joints** 는 고정 베이스(Base) - 각 회전축(J1, J2, …) - 플랜지(Flange) 순서로 넣는다. N축 포지셔너는 평면 N+2 개가 필요하다.
</Aside>
