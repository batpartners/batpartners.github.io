로봇과 연동할 외부축 포지셔너의 기구학 구성을 정의하는 컴포넌트이다. 정의한 포지셔너는 로봇 셋업과 Positioner RobTarget 에서 사용한다.

이 페이지는 컴포넌트를 우클릭하여 <strong>[Define Positioner]</strong> 를 선택했을 때를 설명한다. 카탈로그 모델 대신 포지셔너 링크 메시와 기구학 평면을 직접 지정하므로, 카탈로그에 없는 포지셔너도 정의할 수 있다. 모든 축은 회전 축이어야 한다.

## 사용 순서

<Steps>

1. 컴포넌트를 우클릭하여 **Define Positioner** 를 선택한다.
2. **Positioner Geo** 에 포지셔너 링크 형상 메시를, **Joint Planes** 에 베이스부터 플랜지까지의 기구학 평면 리스트를 연결하고, **ABB Positioner** 탭에서 **Axis Type** 과 **MechUnit Name** 을 정한다.
3. 포지셔너 플랜지 평면이 WorldXY 가 아니면 **Mounting Plane** 을, 워크벤치를 달려면 **Workbench** 에 [CreateWorkBench](/robot-tool/createworkbench/) 출력을 연결한다.
4. **Motion** 탭에서 암 동작(**Enable Arm**)과 TCP 접근·정렬 방향(**Approach Dir**, **TCP Dir**)을, **RAPID** 탭에서 RobTarget 의 외부축 배열에 쓸 **Arm / Plate Joint Index** 를 정한다.
5. **Positioner** 출력을 [ABB Robots](/robot-tool/abbrobot/) 와 [Positioner RobTarget](/datatype/positioner-robtarget-dynamic/) 의 **Positioner** 입력에 연결한다.

</Steps>

## 주의 사항

<Aside type="caution">
  **Arm Joint Index** 와 **Plate Joint Index** 는 다른 외부축 인덱스와 겹치면 안 됩니다. 예: Arm = 2, Plate = 3 → ExtJoint [9E9, arm, plate, 9E9, 9E9, 9E9].
</Aside>

<Aside type="note">
  **Joint Planes** 는 고정 베이스(Base) - 각 회전축(J1, J2, …) - 플랜지(Flange) 순서로 넣습니다. N축 포지셔너는 평면 N+2 개가 필요합니다. **Axis Type** 이 Single Axis (Plate) 이면 **Enable Arm** 과 **Arm Joint Index** 가 숨겨집니다.
</Aside>
