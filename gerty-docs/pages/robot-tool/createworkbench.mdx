포지셔너 플랜지에 장착할 워크벤치(Workbench)와 작업물(Workpiece)을 정의하는 컴포넌트이다. 실제 작업대와 작업물 형상을 시뮬레이션에 반영하여 포지셔너 구동 중 발생할 수 있는 간섭을 검증하고 경로 시뮬레이션을 정밀하게 수행할 수 있다.

이 페이지는 우클릭 메뉴의 기본 모드인 <strong>[Define Workbench]</strong> 를 설명한다. 워크벤치 형상 메시와 기준 평면을 직접 연결하여 정의한다.

## 사용 순서

<Steps>

1. **Workbench Geo** 에 워크벤치 형상 메시를 연결한다.
2. **Base Plane** 에 포지셔너 플랜지에 닿는 워크벤치 하단 기준면을, **Top Plane** 에 작업물이 놓이는 상단 기준면을 연결한다. 작업물이 있으면 **Workpieces** 도 연결한다.
3. **WorkBench** 탭에서 **Name** 을 입력하고, 필요하면 **Preview** 탭에서 워크벤치·작업물 색상을 정한다.
4. **Workbench** 출력을 [ABB Positioner](/robot-tool/positioner/) 의 **Workbench** 입력에 연결한다.
5. 다른 파일에서 같은 워크벤치를 쓰려면 **Export** 탭의 **Export** 로 저장한다. 저장한 워크벤치는 [Import Workbench](/robot-tool/createworkbench-option/) 모드의 **Presets** 에서 불러온다.

</Steps>

## 주의 사항

<Aside type="tip">
  실제 작업대와 작업물 형상을 넣으면 포지셔너가 움직일 때 생기는 간섭을 시뮬레이션에서 미리 확인할 수 있습니다.
</Aside>

<Aside type="note">
  우클릭 메뉴의 **Open Workbench Folder** 로 워크벤치 저장 폴더(`Documents\GERTY\UserAssets\WorkBench`)를 열 수 있습니다.
</Aside>
