로봇과 연동할 외부축 포지셔너의 기구학 구성을 정의하는 컴포넌트이다. 정의한 포지셔너는 로봇 셋업과 Positioner RobTarget 에서 사용한다.

이 페이지는 우클릭 메뉴의 기본 모드인 <strong>[Import Positioner]</strong> 를 설명한다. ABB IRBP 시리즈 카탈로그에서 모델과 사양을 골라 포지셔너를 불러온다. 축 형상을 직접 지정하려면 <strong>[Define Positioner]</strong> 를 선택한다.

## 사용 순서

<Steps>

1. **ABB Positioner** 탭의 **Positioner Model** 에서 ABB IRBP 포지셔너 모델을, **Spec** 에서 작업 직경(D)·플레이트 높이(H) 사양을 고르고, 필요하면 **MechUnit Name** 을 정한다.
2. 포지셔너 플랜지 평면이 WorldXY 가 아니면 **Mounting Plane** 을, 워크벤치를 달려면 **Workbench** 에 [CreateWorkBench](/robot-tool/createworkbench/) 출력을 연결한다.
3. **Motion** 탭에서 암 동작(**Enable Arm**)과 TCP 접근·정렬 방향(**Approach Dir**, **TCP Dir**)을, **RAPID** 탭에서 RobTarget 의 외부축 배열에 쓸 **Arm / Plate Joint Index** 를 정한다.
4. **Positioner** 출력을 [ABB Robots](/robot-tool/abbrobot/) 와 [Positioner RobTarget](/datatype/positioner-robtarget-dynamic/) 의 **Positioner** 입력에 연결한다.

</Steps>

## 주의 사항

<Aside type="caution">
  **Arm Joint Index** 와 **Plate Joint Index** 는 다른 외부축 인덱스와 겹치면 안 됩니다. 예: Arm = 2, Plate = 3 → ExtJoint [9E9, arm, plate, 9E9, 9E9, 9E9].
</Aside>
