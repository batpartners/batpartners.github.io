## How to use

<Steps>

1. Connect a planar surface to **Surface**.
2. Set **U Param** and **V Param** of the plane origin in the **UV Param** tab.
3. If needed, change the size of the preview frame with **Frame Size** in the **Preview** tab.
4. Connect the **Base Plane** output wherever a reference plane is needed (e.g. **BasePlane** of [Overhang Mapper](/en/utils/overhangmapper/)).

</Steps>
