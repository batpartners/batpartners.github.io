Positioner RobTarget defines a RobTarget that includes the positioner (external axis) joint angles. Right-click the component to switch between **Dynamic Mode** and **Static Mode**; this page describes **Static Mode**, selected from the right-click menu. In Static mode the positioner keeps a fixed orientation defined by **Reference Plane**. To rotate the positioner per target, use [Dynamic Mode](/en/datatype/positioner-robtarget-dynamic/).

## How to use

<Steps>

1. Connect the [ABB Positioner](/en/robot-tool/positioner/) component data to **Positioner**.
2. Connect the target planes to **Target Planes** and the plane they are defined in to **Target Base**. If needed, rotate the targets about their own Z axis with **Z Rotation**, and connect **WobjData** to work in a work-object frame.
3. Connect the plane that defines the fixed positioner orientation in Static mode to **Reference Plane**.
4. Connect the **RobTargets** output to a move instruction. To use the start and end targets separately, turn on **Split Start / Split End** in the **Output** tab.

</Steps>

## Notes

<Aside type="tip">
  **Split Start / Split End** take the first and last RobTarget of each Target Planes branch out into dedicated start and end outputs (**Start Target / End Target**).
</Aside>
