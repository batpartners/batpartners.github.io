## How to use

<Steps>

1. Connect the [ABB Positioner](/en/robot-tool/positioner/) component data to **Positioner**.
2. Connect the target planes to **Target Planes** and the plane they are defined in to **Target Base**.
3. Connect the plane that sets the positioner orientation in Static mode to **Reference Plane**.
4. Connect the **RobTargets** output to a move instruction. To use the start and end targets separately, turn on **Split Start / Split End** in the **Output** tab.

</Steps>

## Notes

<Aside type="tip">
  **Split Start / Split End** take the first and last index of each Target Plane branch out into **Start Targets / End Targets**.
</Aside>
