This is a component that defines parameters for the actual welding section where the arc is stably maintained. It allows you to specify welding speed, voltage, wire feed conditions, and other parameters applied along the seam.

## How to use

<Steps>

1. Connect the weld program number (schedule) and mode to **Weld Sched** and the wirefeed1 weighting to **Weighting**. For weaving, connect [WeaveData](/en/datatype/weavedata/) too.
2. Type the variable name in **Name** (WeldData tab).
3. Set voltage, wire feed, control and current in the **Weld ArcData** tab, and **Weld Speed(mm/s)** in the **Weld Param** tab.
4. Connect the **WeldData** output to the **WeldData** input of [ArcMove](/en/instruction/arcmove/).

</Steps>
