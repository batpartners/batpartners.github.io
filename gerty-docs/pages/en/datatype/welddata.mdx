Defines the parameters of the active weld phase, while the arc is established. It specifies the welding speed, voltage, wire-feed conditions and other parameters applied along the seam. Right-click the component to choose the wire-feed unit, **WireFeed(m/min)** or **WireFeed(mm/s)**; this page is based on **WireFeed(m/min)**, the default.

## How to use

<Steps>

1. Connect the weld program number (schedule) and weld mode to **Weld Sched**. If needed, connect the wirefeed1 weighting to **Weight**, and for weaving connect a [WeaveData](/en/datatype/weavedata/) to **WeaveData**.
2. Type the variable name in **Name** (WeldData tab).
3. Set **Voltage**, **WireFeed(m/min)**, **Control** and **Current** in the **Weld ArcData** tab, and **Weld Speed(mm/s)** in the **Weld Param** tab. To enter the wire feed in mm/s, pick **WireFeed(mm/s)** from the right-click menu.
4. Connect the **WeldData** output to the **WeldData** input of [ArcMove](/en/instruction/arcmove/).

</Steps>
