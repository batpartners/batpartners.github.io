## How to use

<Steps>

1. Connect the [ABB Positioner](/en/robot-tool/positioner/) component data to **Positioner**.
2. Connect the target planes to **Target Plane** and the plane they are defined in to **Base Plane**. The targets are aligned from this plane to the positioner mounting plane.
3. If needed, rotate the targets about their own Z axis with **Z Rotation**, and connect **WobjData** to work in a work-object frame.
4. Connect the **RobTargets** output to a move instruction. To use the start and end targets of each path separately, turn on **Split Start / Split End** in the **Output** tab.

</Steps>

## Notes

<Aside type="tip">
  **Split Start / Split End** take the first and last index of each Target Plane branch out into **Start Targets / End Targets**.
</Aside>
