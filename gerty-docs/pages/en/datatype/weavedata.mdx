This component defines the weaving motion performed during arc welding. It specifies the weave shape, amplitude, frequency (cycle length) and dwell parameters, and adjusts the pattern orientation and bias relative to the seam. The pattern can be previewed in the viewport and through the **Pattern** output.

## How to use

<Steps>

1. In the first tab, type the **Name**, pick the weaving pattern (zigzag, V, triangle, circle) with **Weave Shape** and the axis control with **Weave Type**.
2. Set the pattern size with **Length / Width / Height** in the **Dimension** tab.
3. If needed, set the dwell lengths at the turning points and centre in the **Dwell** tab, the pattern direction and tilt angles in the **Orient** tab, and the centreline offset (zigzag only) in the **Bias** tab.
4. To check the pattern, connect a reference plane to **Base Plane** and set the number of cycles to draw with **Preview Cycles** (Preview tab). The **Pattern** output gives the pattern curve.
5. Connect the **WeaveData** output to the **WeaveData** input of [WeldData](/en/datatype/welddata/).

</Steps>

## Notes

<Aside type="note">
  **Height** is used only by the V and triangle patterns; zigzag and circle ignore it. **Weave Bias** applies to the zigzag pattern only.
</Aside>

<Aside type="note">
  What **Length** means depends on the settings: the weaving frequency (Hz) when Weave Type is Rapid_1/Rapid_2, and the distance between circles when Weave Shape is Circular.
</Aside>
