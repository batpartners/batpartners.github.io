Tool Importer is the Import mode of the ToolData component. Right-click the component to switch between **Define ToolData** and **Import ToolData**; this page describes **Import ToolData**, selected from the right-click menu. It loads tool data saved with <strong>Export</strong> in [Define ToolData](/en/datatype/tooldata/) mode and builds an ABB `tooldata`.

## How to use

<Steps>

1. Pick a saved tool from **Presets** in the **Tool Data** tab.
2. Type the RAPID variable name in **Name**. If the mounting plane is not WorldXY, connect **Base Plane**; to change the TCP, connect **TCP** (if not connected, the TCP of the imported tool is used).
3. Connect the **ToolData** output to the **ToolData** input of the [ABB Robots](/en/robot-tool/abbrobot/) component.

</Steps>

## Notes

<Aside type="tip">
  If **Presets** is empty, first save a tool with **Export** in [Define ToolData](/en/datatype/tooldata/) mode. The save folder opens from **Open ToolData Folder** in the right-click menu.
</Aside>
