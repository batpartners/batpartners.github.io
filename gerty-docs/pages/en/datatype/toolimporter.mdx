## How to use

<Steps>

1. Pick a saved tool from **Tool Presets** in the **Tool Data** tab.
2. Type the RAPID variable name in **Name**.
3. Connect the **Tool Data** output to the **Tool Data** input of the [ABB Robots](/en/robot-tool/abbrobot/) component.

</Steps>

## Notes

<Aside type="tip">
  If **Tool Presets** is empty, first save a tool with **Export** in [ToolData](/en/datatype/tooldata/).
</Aside>
