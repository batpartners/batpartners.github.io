Positioner RobTarget defines a RobTarget that includes the positioner (external axis) joint angles. Right-click the component to switch between **Dynamic Mode** and **Static Mode**; this page describes **Dynamic Mode**, the default. In Dynamic mode the positioner rotates per target so that each target's projected Z axis aligns with the approaching direction. To keep the positioner in a fixed orientation, use [Static Mode](/en/datatype/positioner-robtarget-static/).

## How to use

<Steps>

1. Connect the [ABB Positioner](/en/robot-tool/positioner/) component data to **Positioner**.
2. Connect the target planes to **Target Planes** and the plane they are defined in to **Target Base**. The targets are aligned from this plane to the positioner mounting plane.
3. If needed, rotate the targets about their own Z axis with **Z Rotation**, and connect **WobjData** to work in a work-object frame.
4. Connect the **RobTargets** output to a move instruction. To use the start and end targets of each path separately, turn on **Split Start / Split End** in the **Output** tab.

</Steps>

## Notes

<Aside type="tip">
  **Split Start / Split End** take the first and last RobTarget of each Target Planes branch out into dedicated start and end outputs (**Start Target / End Target**).
</Aside>
