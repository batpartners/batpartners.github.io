WobjData defines the coordinate system of the workpiece (work object). It supports intuitive programming based on drawings, and when the installation changes, the program can be reused by correcting only the coordinate system.

It specifies the user frame (uframe), which defines the local coordinate system of the work surface within the world frame, and the object frame (oframe) relative to it. Right-click the component to switch between two modes: **Fixed WobjData** (stationary work object, the default) and **Movable WobjData** (work object moved by an external axis).

This page covers <strong>Movable WobjData</strong>, selected from the right-click menu. In this mode the component takes a positioner instead of frame planes and defines the work object moved by that positioner (external axis).

## How to use

<Steps>

1. Connect the output of [ABB Positioner](/en/robot-tool/positioner/) to **Positioner**.
2. Type the RAPID variable name in **Name** (WobjData tab). Adjust the size of the frame shown in the viewport with **Frame Size** (Preview tab).
3. Connect the **WobjData** output to the **WobjData** input of a target component such as [Positioner RobTarget](/en/datatype/positioner-robtarget-dynamic/) to define targets in the work-object frame.

</Steps>

## Notes

<Aside type="tip">
  With **Override Wobj** connected, that work-object data is output regardless of the other inputs.
</Aside>

<Aside type="note">
  When the setup moves, only the WobjData frames need to change; the robot program can be reused.
</Aside>
