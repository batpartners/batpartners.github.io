Defines the start and end phase data of a welding seam. Allows detailed specification of timing and arc conditions across three phases: Ignition, Heat, and End. Typically, the same values are maintained for an entire seam or across multiple seams.

## How to use

<Steps>

1. Connect the weld program number (schedule) and mode to **Weld Sched**, and the Wirefeed1 weighting to **Weighting**.
2. Type the variable name in **Name** (SeamData tab).
3. Set the arc conditions per phase (Voltage, WireFeed, Control, Current) in the **Ignition / Heat / End ArcData** tabs.
4. Set the timing per phase (gas, heat, crater fill, burn-back and so on) in the **Ignition / Heat / End Params** tabs.
5. Connect the **SeamData** output to the **SeamData** input of [ArcMove](/en/instruction/arcmove/).

</Steps>

## Notes

<Aside type="tip">
  Right-click the component icon to switch the WireFeed unit between m/min and mm/s (ABB and Fronius).
</Aside>

<Aside type="note">
  With Fronius TPS/TPS-i, **Voltage** sets the arc length, **Control** the dynamics, and **Current** is not used.
</Aside>

<Aside type="note">
  **Heat Time(s)** applies only when Heat Distance or Heat Speed is 0.
</Aside>
