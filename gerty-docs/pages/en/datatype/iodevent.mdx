Defines a single I/O trigger event for a TriggIOs array. Specifies the target output signal, trigger position along the path, and configuration values. Multiple IOEvents can be grouped into the TriggIOs component to construct TriggIOs data.

## How to use

<Steps>

1. Connect the signal data to **Signal**.
2. In the **IOData Signal** tab, set **Signal Type** (digital / group / analog) and **DO Value**.
3. In the **Settings** tab, set where the trigger fires: **Start** picks the reference point (start or end of the move), **Distance(mm)** the distance from it, and **EquipLag(sec.)** the response-delay compensation of the external equipment.
4. Collect the **IO Data** outputs of several IOEvents into the **IOs** input of [TriggIOs](/en/datatype/triggios/).

</Steps>

## Notes

<Aside type="tip">
  A positive **EquipLag(sec.)** fires the signal before the set position is reached; a negative one fires it after the position is passed.
</Aside>
