Defines a single I/O trigger event as an element of a TriggIOs array. It specifies the target output signal, the trigger position along the motion path, and the value to write to the signal. Multiple IOEvents are bundled into the [TriggIOs](/en/datatype/triggios/) component to build a complete TriggIOs dataset.

## How to use

<Steps>

1. Connect the name of the output signal to **Signal**.
2. In the **IO Event** tab, choose **Signal Type** (Digital / Group / Analog Output) and set the value in the matching value control (**DO Value** / **GO Value** / **AO Value**).
3. In the **Settings** tab, set where the trigger fires: **Start** picks the reference point (start or end of the move), **Distance** the distance from it (mm), and **EquipLag(s)** the response-delay compensation of the external equipment. Clear **Used** to disable the event temporarily.
4. Collect the **IOEvent** outputs of several IOEvents into the **IOEvent** input of [TriggIOs](/en/datatype/triggios/).

</Steps>

## Notes

<Aside type="tip">
  A positive **EquipLag(s)** fires the signal before the set position is reached; a negative one fires it after the position is passed.
</Aside>
