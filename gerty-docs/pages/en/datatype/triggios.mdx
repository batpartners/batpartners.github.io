Defines a positioning trigger that fires one or more IO Events when the robot reaches a specified point along its path. It bundles several [IOEvents](/en/datatype/iodevent/) under one variable name. Used by the ABB Trigger Move instructions (TriggLIOs, TriggJIOs).

## How to use

<Steps>

1. Collect the **IOEvent** outputs of several [IOEvents](/en/datatype/iodevent/) into the **IOEvent** input.
2. Type the variable name in **Name** (TriggIOs tab).
3. Connect the **TriggIOs** output to [TriggerIOMove](/en/instruction/triggeriomove/).

</Steps>
