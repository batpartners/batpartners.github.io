## How to use

<Steps>

1. Connect the tool mesh to **ToolGeo** and the tool-tip plane to **TCP**. If the mounting plane is not WorldXY, connect it to **ToolBase** too.
2. Type the RAPID variable name in **Name**, and the mass, centre of gravity and inertia in **LoadData** if you know them.
3. Connect the **Tool Data** output to the **Tool Data** input of the [ABB Robots](/en/robot-tool/abbrobot/) component.
4. To reuse the tool in another file, save it with **Export** and pick it from **Tool Presets** in [Tool Importer](/en/datatype/toolimporter/) there.

</Steps>

## Notes

<Aside type="caution">
  With LoadData empty, the load is estimated from the bounding box of the tool shape. It can differ from the real tool, so enter known values.
</Aside>

<Aside type="tip">
  **Name** becomes the RAPID variable name, so follow RAPID naming rules (start with a letter; letters, digits and underscores).
</Aside>
