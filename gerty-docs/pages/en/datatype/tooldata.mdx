Takes the tool (end-effector) shape, mounting plane, TCP and load data, and builds an ABB `tooldata`. Connect it to the ABB Robots component to use it across the whole robot program. Right-click the component to switch between **Define ToolData** (configure manually) and **Import ToolData** (load saved tool data); this page describes **Define ToolData**, the default. To load a saved tool, use [Import ToolData](/en/datatype/toolimporter/) mode.

## How to use

<Steps>

1. Connect the tool mesh to **Tool Geo** and the tool-tip plane to **TCP**. If the mounting plane is not WorldXY, connect it to **Base Plane** too.
2. Type the RAPID variable name in **Name** (Tool Data tab). If you know the load, enter **Mass(kg)**, **Centroid** and **Inertia** in the **LoadData** tab; press **Reset** to calculate it.
3. Connect the **ToolData** output to the **ToolData** input of the [ABB Robots](/en/robot-tool/abbrobot/) component.
4. To reuse the tool in another file, save it in the **Export** tab and pick it from **Presets** in [Import ToolData](/en/datatype/toolimporter/) mode there. The save folder opens from **Open ToolData Folder** in the right-click menu.

</Steps>

## Notes

<Aside type="caution">
  With **Tool Load** not connected, the load is estimated from the bounding box of the tool shape. It can differ from the real tool, so enter known values.
</Aside>

<Aside type="tip">
  **Name** becomes the RAPID variable name, so follow RAPID naming rules (start with a letter; letters, digits and underscores).
</Aside>
