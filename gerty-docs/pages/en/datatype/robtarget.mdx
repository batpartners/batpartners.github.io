RobTarget defines the target position, tool orientation, and axis configuration the robot moves to. It is used for robot-only motion without external axes (positioner); the external axis values are automatically set to `9E9` (unused). For targets that also drive a positioner, use [Positioner RobTarget](/en/datatype/positioner-robtarget-dynamic/).

## How to use

<Steps>

1. Connect the planes to turn into RobTargets to **Target Planes**. If needed, rotate the targets about their own Z axis with **Z Rotation** (degrees).
2. To work in a work-object frame, connect **WobjData**. With **Chaining** on, the targets move along when you move the work-object plane in the viewport.
3. To align the +X axis toward the robot, turn on **Align X** in the **Orientation** tab and set **Robot Base** and **Align Weight**.
4. Connect the **RobTargets** output to a move instruction ([Move](/en/instruction/move/), [ArcMove](/en/instruction/arcmove/)). To use the start and end targets of each path separately, turn on **Split Start / Split End** in the **Output** tab.

</Steps>

## Notes

<Aside type="tip">
  **Split Start / Split End** take the first and last RobTarget of each Target Planes branch out into dedicated start and end outputs (**Start Target / End Target**).
</Aside>

<Aside type="note">
  With **Align Weight** 0 the original orientation is kept; with 1 the +X axis points fully at the Robot Base origin.
</Aside>
