This component generates flyby transition target planes that connect two or more Target Plane DataTrees. It routes the tool away from the workpiece when moving between toolpath DataTrees; the approach and departure directions and distances and the blend shape follow the settings.

## How to use

<Steps>

1. Connect one target plane DataTree each to **Target Planes0** and **Target Planes1**.
2. Pick the approach and departure directions (motion direction or an axis of the target plane) in **Approach Dir** / **Departure Dir** (Offset tab).
3. Set the approach and departure distances (**Approach (mm)** / **Departure (mm)**) in the **Offset** tab and the number of targets on each flyby path (**Target Count**) in the **Flyby Targets** tab. Turn on **Link** to keep both distances equal.
4. Adjust the blend continuity (**Continuity Type**) and the bulge at the start and end (**Bulge Start** / **Bulge End**) in the **Blend** tab.
5. Connect the **Flyby Targets** output to the **Target Plane** input of [RobTarget](/en/datatype/robtarget/) to make robot targets.

</Steps>
