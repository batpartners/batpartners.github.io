This is a component that allows you to set two or more Target Plane paths. It generates flyby target planes connecting between each branch, and reconstructs the path in sections where it leaves the workpiece when moving between path segments to determine the target planes according to user-defined values.

## How to use

<Steps>

1. Connect one target plane DataTree each to **Target Planes0** and **Target Planes1**; add inputs with **+ ADD** for more path trees.
2. Pick the approach and departure directions (motion direction or an axis of the target plane) in **Approaching Dir. / Leaving Dir.** (Basic tab).
3. Set the approach and departure distances (**Approaching / Leaving Dist.(mm)**) and the number of targets on each fly-by path (**Target Count**) in the **Basic** tab.
4. Adjust the blend continuity (**Continuity Type**) and the bulge at the start and end (**Bulge Start / Bulge End**) in the **Advanced** tab.
5. Connect the **Fly-by Targets** output to the **Target Plane** input of [RobTarget](/en/datatype/robtarget/) to make robot targets.

</Steps>
