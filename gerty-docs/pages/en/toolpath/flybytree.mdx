Flyby generates flyby transition target planes that connect toolpath segments. It merges the former FlybyBranch, FlybyCustom and FlybyTree components into one. It routes the tool away from the workpiece when moving between toolpath segments; the approach and departure directions and distances, the blend shape and the orientation interpolation follow the settings. The results are output as transition target planes (**Flyby Targets**) and blend curves (**Flyby Curves**).

Right-click the component to switch between **Between Branches** and **Between Inputs**. This page covers **Between Inputs**, chosen from the right-click menu. In this mode each input (**Target Planes0**, **Target Planes1**) is one segment, and the DataTree of each input is flattened. To build flyby paths between the branches of one DataTree, use the default [Between Branches](/en/toolpath/flybybranch/) mode.

## How to use

<Steps>

1. Right-click the component and choose **Between Inputs**. The component shows **Between Inputs** below it.
2. Connect the target planes of one segment each to **Target Planes0** and **Target Planes1**.
3. In the **Flyby Targets** tab, set the number of targets on each transition path (**Target Count**) and whether to create the stand-alone targets before the first and after the last segment (**Lead In/Out**).
4. In the **Offset** tab, pick the approach and departure directions (motion direction, an axis of the target plane, or **Custom**) in **Approach Dir** / **Departure Dir**, and set the approach and departure distances (**Approach (mm)** / **Departure (mm)**). Turn on **Link** to keep both distances equal. Choosing **Custom** adds a vector input of the same name for setting the direction per segment.
5. Set the blend continuity (**Continuity Type**) and the bulge at the start and end (**Bulge Start** / **Bulge End**) in the **Blend** tab, and the orientation interpolation (**Interpolation**) and rotation flip (**Flip Rotation** / **Flip Over (°)**) in the **Rotation** tab.
6. Place the main toolpath target planes on odd paths `{1}`, `{3}`, …, merge them with the **Flyby Targets** output (even paths) into one DataTree, and connect it to the **Target Plane** input of [RobTarget](/en/datatype/robtarget/) to make robot targets.

</Steps>
