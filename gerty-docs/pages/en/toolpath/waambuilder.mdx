This component processes and integrates the WAAM deposition toolpaths generated by a slicer. It classifies the targets into five categories: first layer (Shell / Infill), subsequent layers (Shell / Infill) and Tween Shell. It also sorts the deposition order and includes a per-layer preview.

## How to use

<Steps>

1. Connect the output of a slicer ([Solid Shell](/en/toolpath/solidshell/), [Surface Shell](/en/toolpath/surfaceshell/), [Solid Fill](/en/toolpath/solidfill/), …) to **Deposition ToolPaths**. The slicer carries the first-part (lowest partition) flag on the paths, so no extra wire is needed.
2. In the **Settings** tab, choose whether infill goes first (**Infill first**), whether several objects are built layer by layer or object by object (**Layer by Layer**), and whether to ignore the first-part distinction (**Ignore First Part**).
3. Check the build order layer by layer with **Layer Preview** (Preview tab).
4. Turn each layer-kind output (**First Shells** / **First Infills**, **Upper Shells** / **Upper Infills**, **Tween Shells**) into [RobTarget](/en/datatype/robtarget/)s and connect them to instructions.

</Steps>

## Notes

<Aside type="note">
  When the input paths are not from the first part, or **Ignore First Part** is TRUE, **First Shells** and **First Infills** have no output.
</Aside>
