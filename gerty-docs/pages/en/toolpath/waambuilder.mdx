This is a component that receives, analyzes, and integrates WAAM deposition toolpaths generated by a slicer. It can separate and output the received data into five categories: First Layer Shell, First Layer Infill, Subsequent Layers Shell, Subsequent Layers Infill, and Tween Shell. Users can preview the alignment and layers of the deposition path.

## How to use

<Steps>

1. Connect the output of a slicer ([Solid Shell](/en/toolpath/solidshell/), [Surface Shell](/en/toolpath/surfaceshell/), [Solid Fill](/en/toolpath/solidfill/), …) to **Deposition ToolPaths**, and the **Is Bottommost** output of Solid Shell / Surface Shell to **Is Bottommost**.
2. In the **Settings** tab, choose whether infill goes first (**Infill first**) and whether several objects are built layer by layer (**Layer by Layer**).
3. Check the build order layer by layer with **Layer Preview** (Preview tab).
4. Turn each layer-kind output (first layer shell / infill, later layer shell / infill, tween shell) into [RobTarget](/en/datatype/robtarget/)s and connect them to instructions.

</Steps>

## Notes

<Aside type="note">
  When **Is Bottommost** is FALSE, **1st Shell Layers** and **1st Infill Layers** have no output.
</Aside>
