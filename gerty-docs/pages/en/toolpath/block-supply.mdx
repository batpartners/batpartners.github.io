## How to use

<Steps>

1. Connect the supply base plane to **Base Plane**, the unit block to **Unit Block** and the **Block Count** output of [Block Designer](/en/toolpath/block-designer/) to **Block Count**.
2. Set the X, Y and Z spacing in the **Spacing** tab and the number of blocks per direction in the **Count** tab.
3. Connect the **Target Planes** output to the **Target Plane** input of [RobTarget](/en/datatype/robtarget/) to make robot targets.

</Steps>

## Notes

<Aside type="caution">
  If **Block Count** exceeds the layout capacity (X × Y × Z), blocks repeat on top of the same layout, so set the **Count** tab large enough.
</Aside>
