This is a component that generates shell deposition toolpaths from a closed solid geometry. It allows you to configure detailed settings such as the starting position, spacing, height, and tilting degree of the target planes. If the geometry is large, it can export the operation data by dividing it into partitions.

This page covers the form with the added <strong>Angle Ranges</strong> and <strong>Multiple</strong> inputs (Extra Option).

## How to use

<Steps>

1. Connect the closed solid (Brep or Mesh) to **Geometry**. To place the seam, connect **Seam Crvs**.
2. Align **Reference Plane** with the build plate (default WorldXY). To tilt targets around edges, connect **Edge Crvs**.
3. Connect the added **Angle Ranges** and **Multiple** inputs.
4. In the **Slicing** tab, set the outline offset (**Setback(mm)**), the number of shells (**Outline Shells**), bead width, layer heights and **Tolerance**.
5. Use the **Tilting** tab to tilt for overhangs or edges, and the **Seam** tab to spread or shift the start points (seam).
6. Connect the **Deposition ToolPaths** and **Is Bottommost** outputs to [Deposition Builder](/en/toolpath/depositionbuilder/) or [WAAM Builder](/en/toolpath/waambuilder/), and, for infill, **GERTYShellData** to [Solid Fill](/en/toolpath/solidfill/) or [Solid Offset Fill](/en/toolpath/solidoffsetfill/).

</Steps>

## Notes

<Aside type="tip">
  For a large part, split the model into N parts with **Partition** and pick the part to slice (1–N) with **Order**, then export part by part.
</Aside>
