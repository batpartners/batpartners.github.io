This is a component that generates a hot-wire cutting toolpath from two curves. Users can set the number of points to generate target planes, the parameter value between the two curves (default: 0.5), and optionally, an attractor value to smoothly adjust the hot-wire tool. In addition, detailed configurations for the hot-wire path direction, tool orientation, and entry intervals are available.

## How to use

<Steps>

1. Connect the two rail curves that define the ruled surface to **Curve A** and **Curve B**.
2. Set the number of targets with **Target Count**. Optionally, set where the target origins lie with **Parameter** (default 0.5) and add an attractor with **Wrist Object** to steer the tool direction smoothly.
3. Set the cutting direction (**Cutting Dir. Flip**), tool direction (**Tool Flip**) and the start/end extension (**Extension(mm)**) in the **Settings** tab.
4. Connect the **Target Planes** output to the **Target Plane** input of [RobTarget](/en/datatype/robtarget/) to make robot targets.

</Steps>
