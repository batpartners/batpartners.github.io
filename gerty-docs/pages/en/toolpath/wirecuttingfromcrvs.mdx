This component generates a hot-wire cutting toolpath from two curves. It builds target planes along the spans of the ruled surface defined by the two rail curves (**Rail A**, **Rail B**); the number of targets, the origin parameter on each span (default 0.5) and an optional attractor that steers the tool direction are set by the inputs. The **Settings** tab sets the cutting direction, tool orientation and start/end extension.

## How to use

<Steps>

1. Connect the two rail curves that define the ruled surface to **Rail A** and **Rail B**.
2. Set the number of targets with **Target Count**. Optionally, set where the target origins lie with **Parameter** (default 0.5) and connect a Point or Curve to **Attractor** to steer the tool direction (target Z).
3. Set the cutting direction (**Dir Flip**), tool direction (**Tool Flip**) and the start/end extension (**Extension**, mm) in the **Settings** tab.
4. Connect the **Target Planes** output to the **Target Plane** input of [RobTarget](/en/datatype/robtarget/) to make robot targets.

</Steps>
