This component generates a hot-wire cutting toolpath from a ruled surface. It builds target planes along the spans of the surface; the number of targets, the origin parameter on each span (default 0.5) and an optional attractor that steers the tool direction are set by the inputs. The **Settings** tab sets the cutting direction, tool orientation, UV direction and start/end extension.

## How to use

<Steps>

1. Connect the ruled surface to **Surface**.
2. Set the number of targets with **Target Count**. Optionally, set where the target origins lie with **Parameter** (default 0.5) and connect a Point or Curve to **Attractor** to steer the tool direction (target Z).
3. Set the cutting direction (**Dir Flip**), tool direction (**Tool Flip**), UV direction (**UV Flip**) and the start/end extension (**Extension**, mm) in the **Settings** tab.
4. Connect the **Target Planes** output to the **Target Plane** input of [RobTarget](/en/datatype/robtarget/) to make robot targets.

</Steps>

## Notes

<Aside type="note">
  **UV Flip** only works on ruled surfaces that are degree 1 in both U and V.
</Aside>
