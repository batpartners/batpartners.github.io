This is a component that generates a hot-wire cutting path from a ruled surface. Users can set the number of points to generate target planes, the internal parameter value of the ruled surface (default: 0.5), and optionally, an attractor value to smoothly adjust the hot-wire tool. In addition, detailed configurations for the hot-wire path direction, tool orientation, and entry intervals are available.

## How to use

<Steps>

1. Connect the ruled surface to **Surface**.
2. Set the number of targets with **Target Count**. Optionally, set where the target origins lie with **Parameter** (default 0.5) and add an attractor with **Wrist Object** to steer the tool direction smoothly.
3. Set the cutting direction (**Cutting Dir. Flip**), tool direction (**Tool Flip**), UV direction (**UV Flip**) and the start/end extension (**Extension(mm)**) in the **Settings** tab.
4. Connect the **Target Planes** output to the **Target Plane** input of [RobTarget](/en/datatype/robtarget/) to make robot targets.

</Steps>

## Notes

<Aside type="note">
  **UV Flip** only works on ruled surfaces that are degree 1 in both U and V.
</Aside>
