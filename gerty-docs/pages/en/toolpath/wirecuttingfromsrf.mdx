This page covers the **WireCutting** component with **From Surface** selected in its right-click menu. It generates a hot-wire cutting toolpath from a ruled surface (**Surface**), placing target planes at the **Spacing** interval along the spans of the surface. Connecting a Point or Curve to the optional **Wrist** input steers the target Z direction toward it. The settings are split into the **Cutting** (target spacing and origin parameter), **Path** (cutting direction, tool orientation, UV direction, extension), **Wrist** (Wrist assignment) and **Preview** tabs. The default **From Curves** mode, which takes two rail curves as input, has its own page: [WireCutting (From Curves)](/en/toolpath/wirecuttingfromcrvs/).

## How to use

<Steps>

1. Right-click the component and select **From Surface**.
2. Connect the ruled surface to **Surface**. When several surfaces are connected, each one produces one branch in the outputs.
3. Set the target spacing (**Spacing**, mm) and the origin position on each span (**Parameter**, default 0.5) in the **Cutting** tab.
4. Set the cutting direction (**Dir Flip**), tool orientation (**Tool Flip**), UV direction (**UV Flip**) and the start/end extension (**Extension**, mm) in the **Path** tab.
5. To steer the tool direction (target Z), connect a Point or Curve to **Wrist**, then set how it is assigned (**Wrist Mode**) and the Sweep guide shape (**Wrist Blend**) in the **Wrist** tab.
6. Connect the **Target Planes** output to the **Target Plane** input of [RobTarget](/en/datatype/robtarget/) to make robot targets.

</Steps>

## Notes

<Aside type="note">
  **UV Flip** only works on ruled surfaces that are degree 1 in both U and V. The switch appears in the **Path** tab only in From Surface mode.
</Aside>

<Aside type="note">
  Turning on **Use Variable Parameters** in the right-click menu adds a **Parameter** input and hides the **Parameter** slider in the **Cutting** tab. Connect either a list of numbers from 0.0 to 1.0 (samples spread evenly along the cutting direction, linearly interpolated in between) or a guide curve (on each span, the point closest to the curve becomes the origin). This option has no page of its own.
</Aside>
