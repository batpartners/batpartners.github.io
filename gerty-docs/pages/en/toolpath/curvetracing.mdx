Curve Tracing generates a robot toolpath that traces the input curves. The **Resolution** tab sets the path precision, and the **Tilting** tab sets the direction and amount of TCP tilt.

## How to use

<Steps>

1. Connect the curves to follow to **Curves** and the toolpath reference plane to **Reference Plane**.
2. Set **Tolerance** and the segment lengths (**Min Edge** / **Max Edge**) in the **Resolution** tab.
3. Set the tilt direction (**Tilt Target**) and amount (**Tilt Weight**) in the **Tilting** tab.
4. Connect the **Target Planes** output to the **Target Plane** input of [RobTarget](/en/datatype/robtarget/) to make robot targets.

</Steps>

## Notes

<Aside type="note">
  With **Tilt Weight** 0.0 the TCP follows the Z direction of **Reference Plane**; with 1.0 it follows the direction set by **Tilt Target** (surface normal or curve tangent).
</Aside>
