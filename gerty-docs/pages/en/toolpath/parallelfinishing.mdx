This component generates a finishing toolpath along parallel contours (Parallel) or the UV isocurves of a surface (UV). It merges the former ParallelFinishing and UVFinishing components; choose one of the two patterns in **Pattern** on the **Cutting** tab.

- **Parallel**: Builds the passes along sections cut by evenly spaced parallel planes. It accepts both Breps and Meshes, and the pass direction is based on **Reference Plane**.
- **UV**: Builds the passes along the UV isocurves of each face. Only Breps (surfaces) are used; Meshes are skipped.

The pass spacing (Stepover), primary direction, linking between passes, TCP tilt and approximation tolerance can be set, and the result is output as target planes and contour polylines.

## How to use

<Steps>

1. Connect the shape to finish (Brep or Mesh) to **Model** and the path reference plane to **Reference Plane**.
2. In the **Cutting** tab, choose Parallel or UV in **Pattern** and set the pass spacing (**Stepover**, mm) and **Tolerance**. The UV pattern builds passes on Breps only.
3. In the **Path** tab, set the primary direction (**Dir Flip**), the linking between passes (**Link**) and the tilt toward the surface normal (**Tilt Weight**).
4. Connect the **Target Planes** output to the **Target Plane** input of [RobTarget](/en/datatype/robtarget/) to make robot targets.

</Steps>
