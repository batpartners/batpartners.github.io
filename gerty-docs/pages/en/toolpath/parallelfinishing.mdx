This component generates a finishing toolpath along parallel contour curves in a single direction. The contour direction, pass spacing (Stepover), TCP tilt and approximation tolerance can be set to suit the workpiece, and the result is output as target planes and contour polylines.

## How to use

<Steps>

1. Connect the shape to finish (Brep or Mesh) to **Geometry** and the path reference plane to **Reference Plane**.
2. Set the contour direction (**Contour Dir**), pass spacing (**Stepover**, mm), tilt toward the surface normal (**Tilt Weight**) and **Tolerance** in the **Settings** tab.
3. Connect the **Target Planes** output to the **Target Plane** input of [RobTarget](/en/datatype/robtarget/) to make robot targets.

</Steps>
