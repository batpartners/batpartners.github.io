This is a component that generates a finishing toolpath along unidirectional parallel contour curves. Users can configure detailed settings such as the distance between target planes, layer-to-layer spacing, and tilting to suit the workpiece geometry.

## How to use

<Steps>

1. Connect the shape to finish (Brep or Mesh) to **Geometry** and the path reference plane to **Reference Plane**.
2. Set the path direction (**Cutting Direction**), path spacing (**Stepover(mm)**), tilt toward the surface normal (**Tilting Weight**) and **Tolerance** in the **Settings** tab.
3. Connect the **Target Planes** output to the **Target Plane** input of [RobTarget](/en/datatype/robtarget/) to make robot targets.

</Steps>
