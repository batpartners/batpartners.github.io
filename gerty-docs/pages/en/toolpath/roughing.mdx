This component generates a stepped roughing toolpath from the stock (Stock) and the final shape (Model). Each layer is cut with concentric rings, and undercuts are protected for 3-axis machining (the tool comes from above). The **Cutting** tab sets the tool diameter, pass and layer spacing and tolerance; the **Allowance** tab sets the finishing allowances left sideways (**Radial**) and upward (**Axial**); the **Path** tab sets the milling mode, ring order, start point, retract clearance and the moves between rings made at depth (**Stay Down**).

## How to use

<Steps>

1. Connect the final shape to keep to **Model** and the stock before machining to **Stock** (both closed Brep or Mesh). If the reference plane is not WorldXY, connect **Reference Plane** too.
2. In the **Cutting** tab, set the tool diameter (**Tool Diameter**), pass spacing (**Stepover**), layer depth (**Stepdown**) and **Tolerance**.
3. In the **Allowance** tab, set the sideways allowance (**Radial**) and the upward allowance (**Axial**).
4. In the **Path** tab, set the milling mode (**Climb**), ring order (**Path Order**), start point (**Seam**), retract clearance (**Clearance**) and the maximum length of moves made at depth (**Stay Down**).
5. Connect the **Target Planes** output to the **Target Plane** input of [RobTarget](/en/datatype/robtarget/) to make robot targets.

</Steps>

## Notes

<Aside type="note">
  **Climb** selects climb or conventional milling for a clockwise (CW · M3) spindle. The direction of each ring is then chosen from the side the uncut material is on, which depends on **Path Order**.
</Aside>

<Aside type="caution">
  A **Stepover** larger than **Tool Diameter** leaves material between the rings.
</Aside>

<Aside type="caution">
  **Stock** is marked optional, but no toolpath is generated without it.
</Aside>
