## How to use

<Steps>

1. Connect the volume to cut (Brep or Mesh) to **Geometry**. If the reference plane is not WorldXY, connect **Reference Planes** too.
2. Set the cutting direction (**Cutting Direction**), outline offset (**Setback(mm)**), path spacing (**Stepover(mm)**), layer depth (**Stepdown(mm)**) and **Tolerance** in the **Settings** tab.
3. Connect the **Target Planes** output to the **Target Plane** input of [RobTarget](/en/datatype/robtarget/) to make robot targets.

</Steps>

## Notes

<Aside type="note">
  **Cutting Direction** flips the direction within each layer (clockwise / counter-clockwise); together with the end mill rotation it decides climb or conventional cutting.
</Aside>
