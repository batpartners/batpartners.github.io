This component generates a stepped roughing toolpath from the stock (Stock) and the final shape (Part). Each layer is cut with concentric rings, and undercuts are protected for 3-axis machining (the tool comes from above). The **Tool** tab sets the tool diameter, cut spacing and allowances; the **Path** tab sets the milling mode, ring order, start point and retract height.

## How to use

<Steps>

1. Connect the final shape to keep (closed Brep or Mesh) to **Part**. If you have a separate stock shape, connect it to **Stock**; if the reference plane is not WorldXY, connect **Reference Plane** too.
2. In the **Tool** tab, set the tool diameter (**Tool Diameter**), pass spacing (**Stepover**), layer depth (**Stepdown**), wall and floor allowances (**Stock to Leave** / **Floor Stock**) and **Tolerance**.
3. In the **Path** tab, set the milling mode (**Climb**), ring order (**Path Order**), start point (**Seam**) and retract height (**Clearance**).
4. Connect the **Target Planes** output to the **Target Plane** input of [RobTarget](/en/datatype/robtarget/) to make robot targets.

</Steps>

## Notes

<Aside type="note">
  **Climb** selects climb or conventional milling for a clockwise (CW · M3) spindle. The direction of each ring is then chosen from the side the uncut material is on, which depends on **Path Order**.
</Aside>

<Aside type="caution">
  A **Stepover** larger than **Tool Diameter** leaves material between the rings.
</Aside>
