This is a component that generates a shell (or perimeter) deposition toolpath for open surface geometries. It allows for detailed configurations such as target plane spacing, height, working direction (zigzag, one-way), and tilting angle. For large geometries, the working data can be exported by dividing it into partitions. Right-clicking the icon allows you to switch to the Use AntiOverhang mode, which enables detailed settings for workpieces with overhangs.

This page covers the form with the added <strong>Angle Ranges</strong> and <strong>Multiple</strong> inputs (Extra Option).

## How to use

<Steps>

1. Connect the open surface (Brep or Mesh) to **Geometry**. To change the direction per layer, connect a boolean pattern to **Direction Change**.
2. Align **Reference Plane** with the build plate (default WorldXY). To tilt targets around edges, connect **Edge Crvs**.
3. Connect the added **Angle Ranges** and **Multiple** inputs.
4. In the **Slicing** tab, set the end finish (**End Fillet Type**), the number of shells (**Outline Shells**), bead width, layer heights and **Tolerance**.
5. Use the **Tilting** tab to tilt for overhangs or edges, and the **Seam** tab to spread or shift the start points (seam).
6. Connect the **Deposition ToolPaths** and **Is Bottommost** outputs to [Deposition Builder](/en/toolpath/depositionbuilder/) or [WAAM Builder](/en/toolpath/waambuilder/).

</Steps>

## Notes

<Aside type="tip">
  For a large part, split the model into N parts with **Partition** and pick the part to slice (1–N) with **Order**, then export part by part.
</Aside>
