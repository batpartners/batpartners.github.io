## How to use

<Steps>

1. Connect the unit block (Box) to **Unit Block** and the wall to build (Brep) to **Wall**. If the slicing base is not WorldXY, connect **Wall Base** too.
2. Set the spacing method (**Divide by Distance**) and the horizontal and vertical spacing in the **Settings** tab.
3. Connect the **Block Count** output to the **Block Count** input of [Block Supply](/en/toolpath/block-supply/).
4. Connect the **Place Targets** output to the **Target Plane** input of [RobTarget](/en/datatype/robtarget/) to make robot targets.

</Steps>
