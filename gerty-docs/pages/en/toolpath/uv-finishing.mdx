This component generates a finishing toolpath that follows the UV isoparametric curves of a surface. The UV direction, pass spacing (Stepover), TCP tilt and approximation tolerance can be set to suit the job, and the result is output as target planes and contour polylines.

## How to use

<Steps>

1. Connect the surface to finish (Brep or Surface) to **Geometry** and the path reference plane to **Reference Plane**.
2. Choose the U or V direction (**UV Flip**), pass spacing (**Stepover**, mm), tilt toward the surface normal (**Tilt Weight**) and **Tolerance** in the **Settings** tab.
3. Connect the **Target Planes** output to the **Target Plane** input of [RobTarget](/en/datatype/robtarget/) to make robot targets.

</Steps>
