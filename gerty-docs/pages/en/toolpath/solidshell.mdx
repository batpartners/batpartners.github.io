This is a component that generates shell deposition toolpaths from a closed solid geometry (Brep or Mesh). You can set the layer height and bead width, the shell method (Contour or Zigzag weaving), target plane tilting, and the seam (start point) and wiping. For a large geometry, the work data can be exported in parts. Enabling `Use AntiOverhang` from the icon's right-click menu adds inputs for overhang reinforcement. The right-click menu also has a `Use Exclusion` option.

## How to use

<Steps>

1. Connect the closed solid (Brep or Mesh) to **Model**. To place the seam with a curve, connect **Seams**.
2. Align **Reference Plane** with the build plate (default WorldXY). To tilt targets around edges, connect **Edges**.
3. In the **Slicing** tab, set the layer heights, **Tolerance** and the section method (**Section Proxy**).
4. In the **Shell** tab, choose the **Shell Type** and bead width (**Layer Width**). For Contour, use **Setback**, **Outline Shells** and **Path Order**; for Zigzag, use **Shell Thickness** and the **Zigzag** and **Relief** tabs to shape the weave.
5. Use the **Tilt** tab to tilt for overhangs or edges, and the **Seam** tab to adjust the start points (seam) and wiping.
6. Connect the **Shell ToolPaths** output to [Deposition Builder](/en/toolpath/depositionbuilder/) or [WAAM Builder](/en/toolpath/waambuilder/), and, for infill, **Shell Profile** to the **Shell Profile** input of [Solid Fill](/en/toolpath/solidfill/).

</Steps>

## Notes

<Aside type="tip">
  For a large part, split the model into N parts with **Part Count** in the **Partition** tab and pick the part to slice (1–N) with **Part Number**, then export part by part.
</Aside>

<Aside type="note">
  Setting **Shell Type** to Zigzag shows the **Zigzag** and **Relief** tabs and the **Phase Pattern** input on the component, and hides **Setback** and **Outline Shells**.
</Aside>

<Aside type="note">
  The `Use Exclusion` option in the icon's right-click menu is not covered in these docs yet.
</Aside>
