This is a deposition toolpath component that fills the inside of the shell with a Linear (parallel-line) or Concentric (offset-ring) pattern, based on the Shell Profile. You can set the pattern angles and phase, the number of top and bottom solid layers, the infill density and gaps, tilting near walls, and wiping and seam placement. The icon's right-click menu also has a `Use Exclusion` option.

## How to use

<Steps>

1. Connect the **Shell Profile** output of [Solid Shell](/en/toolpath/solidshell/) to **Shell Profile**. To tilt the infill near walls, connect the sliced geometry to **Model**.
2. Choose the **Pattern** in the **Pattern** tab. For Linear, set the line pattern with **Type**, **Rotation(°)**, **Phase Shift** and so on (with Type set to Custom, use the **Pattern Angles** input); for Concentric, set the ring order with **Path Order**.
3. In the **Infill** tab, set the number of top and bottom solid layers (**Top Layers**, **Bottom Layers**), the gap to the shell and skin (**Fill Gap**) and the interior density (**Infill Density**).
4. If needed, adjust **Wall Tilt Weight** and **Tilt Ramp** in the **Tilt** tab, and **Wipe Dist** and (for Concentric) the seam placement in the **Seam** tab.
5. Connect the **Infill ToolPaths** output to [Deposition Builder](/en/toolpath/depositionbuilder/) or [WAAM Builder](/en/toolpath/waambuilder/).

</Steps>

## Notes

<Aside type="note">
  Setting **Pattern** to Concentric hides **Type**, **Rotation(°)**, **Phase Shift**, **Alt Connect** and **Raster**, and shows **Path Order** and the seam placement settings in the **Seam** tab (**Seam**, **Seam Spread**, **Ring Spread**, **Seam Offset**).
</Aside>

<Aside type="note">
  The `Use Exclusion` option in the icon's right-click menu is not covered in these docs yet.
</Aside>
