This component processes and integrates the deposition toolpaths generated by the slicer components. It classifies each target, in travel order, as extrusion start (E-Start), extrusion move (E-Move), extrusion end (E-End) or wipe (E-Wipe). Assign per-motion instructions to the four outputs and Merge them in order to complete the path. It also sorts the deposition order and includes a per-layer preview.

## How to use

<Steps>

1. Connect the output of a slicer ([Solid Shell](/en/toolpath/solidshell/), [Surface Shell](/en/toolpath/surfaceshell/), [Solid Fill](/en/toolpath/solidfill/), …) to **Deposition ToolPaths** and a reference plane to **Reference Plane**. To prime the nozzle before extrusion, connect **PreExtrusion Curve** too.
2. In the **Settings** tab, choose whether infill goes first (**Infill first**), whether several objects are built layer by layer or object by object (**Layer by Layer**), and whether to ignore the first-part distinction (**Ignore First Part**).
3. Check the build order layer by layer with **Layer Preview** (Preview tab).
4. Turn **E-Start Planes**, **E-Move Planes**, **E-End Planes** and **E-Wipe Planes** into [RobTarget](/en/datatype/robtarget/)s, connect them to the per-motion instructions, and Merge them in this order.

</Steps>

## Notes

<Aside type="note">
  **PreExtrusion Curve** is added only when the input paths belong to the first (lowest) partition part. The slicer carries this flag on the paths; when **Ignore First Part** is TRUE, the pre-extrusion path is skipped.
</Aside>
