This is a component that receives, analyzes, and integrates deposition toolpaths generated from a slicer component. Among the received data, it can separate and output them by purpose, such as extrusion start (E-Start), move, and extrusion end (E-Stop). Users can preview the alignment and layers of the deposition path.

## How to use

<Steps>

1. Connect the output of a slicer ([Solid Shell](/en/toolpath/solidshell/), [Surface Shell](/en/toolpath/surfaceshell/), [Solid Fill](/en/toolpath/solidfill/), …) to **Deposition ToolPaths**, and the **Is Bottommost** output of Solid Shell / Surface Shell to **Is Bottommost**. To prime the nozzle before extrusion, connect **Pre-Extrusion Curve** too.
2. In the **Settings** tab, choose whether infill goes first (**Infill first**) and whether several objects are built layer by layer (**Layer by Layer**).
3. Check the build order layer by layer with **Layer Preview** (Preview tab).
4. Turn **E-Start Planes**, **Movement Planes** and **E-Stop Planes** into [RobTarget](/en/datatype/robtarget/)s and connect them to instructions. Use **E-Stop idx** when merging the per-target instructions.

</Steps>

## Notes

<Aside type="note">
  When **Is Bottommost** is FALSE (not the bottom part), **Pre-Extrusion Curve** is ignored.
</Aside>
