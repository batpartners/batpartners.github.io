## 2. Open a template

<NumberedShot src="/assets/images/Tutorial_Menu.png" alt="The GERTY Ver.2 menu in Grasshopper with its Templates submenu" width={560} marks={[[48, 4.3], [33.5, 59.1], [89, 76], [33.5, 66.3]]} />

<MarkedSteps>

1. Open **GERTY Ver.2** in the Grasshopper menu bar.
2. Point to **Templates**.
3. Pick a type in the submenu (Basic, Drawing, Hot-wire Cutting, Milling, 3D Printing, Block Laying, WAAM) to open its example definition on the canvas.
4. **Video Tutorials** opens the tutorial videos and **Documents** opens these docs.

</MarkedSteps>

## 4. Apply it to your work

<Steps>

1. Open the template closest to your work and run the simulation once to see the whole motion.
2. In the **Robot setup** stage, change the robot, tool and work object frame to match your cell ([ABB Robots](/en/robot-tool/abbrobot/), [ToolData](/en/datatype/tooldata/), [WobjData](/en/datatype/wobjdata/)).
3. Replace the template's example geometry with yours and adjust the **Toolpath** settings (spacing, layer height and so on).
4. Check reach and collisions with [Display Solver](/en/core/display-solver/), then write the RAPID code with [Code Solver](/en/core/code-solver/).

</Steps>
