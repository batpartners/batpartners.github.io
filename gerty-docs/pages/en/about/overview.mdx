GERTY is CAM software that helps you program custom fabrication with robotic arms. This page introduces GERTY and explains the layout and controls that all its components share.

<DocTags tags={[{ text: "About GERTY", tone: "accent" }, { text: "Overview" }, { text: "Using components" }]} />

## 1. What is GERTY?

<NumberedShot src="/assets/images/GERTY_Laptop.png" alt="GERTY" width={560} marks={[]} />

GERTY is a software framework that runs in Rhino–Grasshopper. It plans and generates additive and subtractive toolpaths that fit the robot arm and its external axes, simulates the motion in 3D, and writes the robot control program: an offline programming (OLP) solution for the robotic custom-manufacturing systems from BAT Partners.

Robot machining motions can be optimised intuitively from CAD data. Because it uses Grasshopper's visual programming interface, you can build custom toolpaths without writing code.

GERTY fully supports ABB multi-axis robot arms and external axes today, and support for other industrial and collaborative robot makers such as Kuka, Fanuc, Hyundai, Universal Robots and Yaskawa is being built.

## 2. Component layout

GERTY components follow the structure of Grasshopper components. Connect the inputs, choose the settings in the GERTY UI, and the result goes out through the outputs.

<NumberedShot src="/assets/images/Component_2026.png" dark="/assets/images/Component_2026_dark.png" alt="A GERTY component: INPUT, ICON, OUTPUT and GERTY UI" width={420} marks={[]} />

| Part | What it does |
| --- | --- |
| **INPUT** | Connect Rhino or GERTY components, or type values in. |
| **ICON** | Right-click it to open the context menu (mode options and more). |
| **OUTPUT** | Passes the result on to the next component. |
| **GERTY UI** | The settings area at the bottom of the component, split into tabs. |

## 3. Inputs

Some inputs are required; optional ones can be left empty.

<Aside type="note">
  Optional inputs can stay empty. When every required value is in place the component turns grey, which is the normal state.
</Aside>

## 4. GERTY UI

The settings area at the bottom of a component. Every setting has a GERTY default that you can change. It uses the same kinds of elements as Grasshopper (Text, Slider, Button, Toggle, DropDown, Panel, Color), grouped by function into tabs.

### Tab

Settings are grouped into tabs by function. The selected tab turns dark and its settings can be changed; required values you leave alone keep the GERTY default. Main functions use vertical tabs and their details horizontal tabs; move between tabs to set the values.
