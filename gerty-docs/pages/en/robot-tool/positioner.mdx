A component that defines the kinematic configuration of an external-axis positioner used with the robot. The positioner is then used in the robot setup and in Positioner RobTarget.

This page covers <strong>[Import Positioner]</strong>, the default mode in the right-click menu: you pick a model and variant from the ABB IRBP series catalog. To specify the axis geometry yourself, select <strong>[Define Positioner]</strong>.

## How to use

<Steps>

1. In the **ABB Positioner** tab, pick the ABB IRBP positioner model in **Positioner Model** and the working diameter (D) / plate height (H) variant in **Spec**; set **MechUnit Name** if needed.
2. If the flange plane is not WorldXY, connect **Mounting Plane**; to mount a workbench, connect the [CreateWorkBench](/en/robot-tool/createworkbench/) output to **Workbench**.
3. Set the arm motion (**Enable Arm**) and the TCP approach and alignment directions (**Approach Dir**, **TCP Dir**) in the **Motion** tab, and the **Arm / Plate Joint Index** used in the RobTarget external-axis array in the **RAPID** tab.
4. Connect the **Positioner** output to the **Positioner** input of [ABB Robots](/en/robot-tool/abbrobot/) and [Positioner RobTarget](/en/datatype/positioner-robtarget-dynamic/).

</Steps>

## Notes

<Aside type="caution">
  **Arm Joint Index** and **Plate Joint Index** must not overlap other external-axis indices. Example: Arm = 2, Plate = 3 → ExtJoint [9E9, arm, plate, 9E9, 9E9, 9E9].
</Aside>
