## How to use

<Steps>

1. Connect the link meshes to **PositionerGeo** and the kinematic plane list from base to flange to **Joints**, then pick the **Axis Type**.
2. If the flange plane is not WorldXY, connect **MountingPl**; to mount a workbench, connect the [CreateWorkBench](/en/robot-tool/createworkbench/) output to **WorkBench**.
3. Set the arm motion (**Enable Arm**) and the TCP approach and alignment directions in **Motion Settings**, and the **Arm / Plate Joint Index** used in the RobTarget external-axis array in **RAPID Setting**.
4. Connect the **Positioner** output to the **Positioner** input of [ABB Robots](/en/robot-tool/abbrobot/) and [Positioner RobTarget](/en/datatype/positioner-robtarget/).

</Steps>

## Notes

<Aside type="caution">
  **Arm Joint Index** and **Plate Joint Index** must not overlap other external-axis indices. Example: Arm = 2, Plate = 3 → ExtJoint [9E9, arm, plate, 9E9, 9E9, 9E9].
</Aside>

<Aside type="note">
  Give **Joints** in order: fixed base, each rotation axis (J1, J2, …), then the flange. An N-axis positioner needs N+2 planes.
</Aside>
