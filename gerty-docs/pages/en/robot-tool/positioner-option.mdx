A component that defines the kinematic configuration of an external-axis positioner used with the robot. The positioner is then used in the robot setup and in Positioner RobTarget.

This page covers the component with <strong>[Define Positioner]</strong> selected in the right-click menu. Instead of a catalog model, you specify the link meshes and kinematic planes yourself, so positioners outside the catalog can be defined. All axes must be rotational.

## How to use

<Steps>

1. Right-click the component and select **Define Positioner**.
2. Connect the link meshes to **Positioner Geo** and the kinematic plane list from base to flange to **Joint Planes**, then set **Axis Type** and **MechUnit Name** in the **ABB Positioner** tab.
3. If the flange plane is not WorldXY, connect **Mounting Plane**; to mount a workbench, connect the [CreateWorkBench](/en/robot-tool/createworkbench/) output to **Workbench**.
4. Set the arm motion (**Enable Arm**) and the TCP approach and alignment directions (**Approach Dir**, **TCP Dir**) in the **Motion** tab, and the **Arm / Plate Joint Index** used in the RobTarget external-axis array in the **RAPID** tab.
5. Connect the **Positioner** output to the **Positioner** input of [ABB Robots](/en/robot-tool/abbrobot/) and [Positioner RobTarget](/en/datatype/positioner-robtarget-dynamic/).

</Steps>

## Notes

<Aside type="caution">
  **Arm Joint Index** and **Plate Joint Index** must not overlap other external-axis indices. Example: Arm = 2, Plate = 3 → ExtJoint [9E9, arm, plate, 9E9, 9E9, 9E9].
</Aside>

<Aside type="note">
  Give **Joint Planes** in order: fixed base, each rotation axis (J1, J2, …), then the flange. An N-axis positioner needs N+2 planes. With **Axis Type** set to Single Axis (Plate), **Enable Arm** and **Arm Joint Index** are hidden.
</Aside>
