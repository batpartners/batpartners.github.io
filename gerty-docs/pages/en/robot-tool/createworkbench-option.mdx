A component that allows users to define a custom workbench for a positioner. By applying the modeling of the currently used workbench to the simulation, you can smoothly monitor the positioner working process. In addition, you can work with a complete simulation including the modeling of workpieces on the workbench.

This page covers loading a workbench saved with <strong>Export</strong> from <strong>Bench Presets</strong>.

## How to use

<Steps>

1. Pick a saved workbench in **Bench Presets** (WorkBench tab).
2. Connect the bottom plane of the workbench (on the positioner flange) to **BenchBase** and the top plane the workpiece sits on to **BenchTop**. Connect **WorkPieces** if there is a workpiece.
3. Type the **Name** and, if you like, set the workbench and workpiece colours.
4. Connect the **WorkBench** output to the **WorkBench** input of [ABB Positioner](/en/robot-tool/positioner/).

</Steps>

## Notes

<Aside type="tip">
  With the real workbench and workpiece shapes in place, collisions while the positioner moves show up in the simulation.
</Aside>
