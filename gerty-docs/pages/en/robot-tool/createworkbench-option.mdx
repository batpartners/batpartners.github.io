A component that defines the workbench and workpieces mounted on the positioner flange. With the real workbench and workpiece shapes in the simulation, you can check for collisions while the positioner moves and simulate paths accurately.

This page covers the component with <strong>[Import Workbench]</strong> selected in the right-click menu. The workbench saved with <strong>Export</strong> is loaded from <strong>Presets</strong> in the <strong>WorkBench</strong> tab, so there is no geometry mesh input.

## How to use

<Steps>

1. Right-click the component and select **Import Workbench**.
2. Pick a saved workbench in **Presets** (WorkBench tab).
3. Connect the bottom plane of the workbench (on the positioner flange) to **Base Plane**. To change the top reference plane, connect **Top Plane** (when not connected, the saved Top Plane is used); connect **Workpieces** if there is a workpiece.
4. If needed, set the **Name** and the workbench and workpiece colors in the **Preview** tab.
5. Connect the **Workbench** output to the **Workbench** input of [ABB Positioner](/en/robot-tool/positioner/).

</Steps>

## Notes

<Aside type="tip">
  With the real workbench and workpiece shapes in place, collisions while the positioner moves show up in the simulation.
</Aside>

<Aside type="note">
  The **Presets** list shows workbenches saved with Export. **Open Workbench Folder** in the right-click menu opens the save folder (`Documents\GERTY\UserAssets\WorkBench`).
</Aside>
