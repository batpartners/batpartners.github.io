A component that defines the ABB robot to use. You select the robot model and variant from the predefined specifications of the ABB IRB series catalog, and the component bundles the base plane, tool, positioner, and surrounding meshes into a single robot setup (Robot Setup). Right-click the component and turn on <strong>[Show Joint Jog Params]</strong> to add the <strong>Robot Joint Jog</strong> / <strong>External Joint Jog</strong> tabs, where you can move the robot joints and external axes directly.

## How to use

<Steps>

1. In the **ABB Robots** tab, pick the ABB robot model in **Robot Model** and the payload / reach variant in **Spec**.
2. Connect [ToolData](/en/datatype/tooldata/) to **ToolData**. If the robot base is not WorldXY, connect **Base Plane**; with a positioner, connect [ABB Positioner](/en/robot-tool/positioner/) to **Positioner**; connect surrounding geometry such as a pedestal to **Pedestal**.
3. If needed, reset the pose (**Reset Pose**) or align the TCP with a World axis (**Align Gumball**) in the **Robot Linear Jog** tab, and check the current TCP plane through the **Current TCP** output.
4. Connect the **Robot Setup** output to the **Robot Setup** input of [GERTY Core](/en/core/gerty-core/).

</Steps>

## Notes

<Aside type="note">
  With **Config Option** (Robot Linear Jog tab) on, cfx = 1: the configuration of robot axes 4 and 6 is inverted. Off means cfx = 0 (default configuration); it is off by default.
</Aside>

<Aside type="tip">
  **Align Gumball** aligns the TCP with the World axis (±X, ±Y, ±Z) closest to its current direction, like Align in ABB FlexPendant jogging.
</Aside>
