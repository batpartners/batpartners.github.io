A component that defines the ABB robot to use. You select the robot model and variant from the predefined specifications of the ABB IRB series catalog, and the component bundles the base plane, tool, positioner, and surrounding meshes into a single robot setup (Robot Setup).

This page covers the component with <strong>[Show Joint Jog Params]</strong> turned on from the right-click menu. This adds the <strong>Robot Joint Jog</strong> tab (robot axes 1–6) and the <strong>External Joint Jog</strong> tab (external axes 1–6), where you move each axis directly to check the pose.

## How to use

<Steps>

1. Right-click the component and turn on **Show Joint Jog Params**.
2. In the **ABB Robots** tab, pick the ABB robot model in **Robot Model** and the payload / reach variant in **Spec**.
3. Connect [ToolData](/en/datatype/tooldata/) to **ToolData**. If the robot base is not WorldXY, connect **Base Plane**; with a positioner, connect [ABB Positioner](/en/robot-tool/positioner/) to **Positioner**; connect surrounding geometry such as a pedestal to **Pedestal**.
4. Move the robot axes (**RobAx 1–6**) in the **Robot Joint Jog** tab and the external axes (**ExtAx 1–6**) in the **External Joint Jog** tab to check the pose. The **Current TCP** output gives the current TCP plane.
5. Connect the **Robot Setup** output to the **Robot Setup** input of [GERTY Core](/en/core/gerty-core/).

</Steps>

## Notes

<Aside type="note">
  With **Config Option** (Robot Linear Jog tab) on, cfx = 1: the configuration of robot axes 4 and 6 is inverted. Off means cfx = 0 (default configuration); it is off by default.
</Aside>

<Aside type="tip">
  **Align Gumball** aligns the TCP with the World axis (±X, ±Y, ±Z) closest to its current direction, like Align in ABB FlexPendant jogging.
</Aside>
