A component that defines the workbench and workpieces mounted on the positioner flange. With the real workbench and workpiece shapes in the simulation, you can check for collisions while the positioner moves and simulate paths accurately.

This page covers <strong>[Define Workbench]</strong>, the default mode in the right-click menu. You define the workbench by connecting its mesh and reference planes directly.

## How to use

<Steps>

1. Connect the workbench mesh to **Workbench Geo**.
2. Connect the bottom plane of the workbench (on the positioner flange) to **Base Plane** and the top plane the workpiece sits on to **Top Plane**. Connect **Workpieces** if there is a workpiece.
3. Enter the **Name** in the **WorkBench** tab and, if needed, set the workbench and workpiece colors in the **Preview** tab.
4. Connect the **Workbench** output to the **Workbench** input of [ABB Positioner](/en/robot-tool/positioner/).
5. To reuse the workbench in another file, save it with **Export** in the **Export** tab. Saved workbenches are loaded from **Presets** in [Import Workbench](/en/robot-tool/createworkbench-option/) mode.

</Steps>

## Notes

<Aside type="tip">
  With the real workbench and workpiece shapes in place, collisions while the positioner moves show up in the simulation.
</Aside>

<Aside type="note">
  **Open Workbench Folder** in the right-click menu opens the folder where workbenches are saved (`Documents\GERTY\UserAssets\WorkBench`).
</Aside>
