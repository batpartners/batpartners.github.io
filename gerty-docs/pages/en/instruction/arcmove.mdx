A component that creates ABB arc instructions (`ArcLStart`, `ArcL`, `ArcLEnd`) for welding. It makes an arc move for each input RobTarget and takes the weld start / end conditions and weld conditions from [SeamData](/en/datatype/seamdata/) and [WeldData](/en/datatype/welddata/). Whether the first and last targets use `ArcLStart` and `ArcLEnd` is set in the settings.

## How to use

<Steps>

1. Connect the [RobTarget](/en/datatype/robtarget/) or [Positioner RobTarget](/en/datatype/positioner-robtarget-dynamic/) output of the weld path to **RobTargets**.
2. Connect [SeamData](/en/datatype/seamdata/) to **SeamData** and [WeldData](/en/datatype/welddata/) to **WeldData**.
3. In the **Arc Move** tab, pick the motion type, speed and zone with **Arc**, and choose whether the first target starts with `ArcLStart` (**Arc Start**) and the last ends with `ArcLEnd` (**Arc End**).
4. Put the **Instruction** output at its place in the instruction list connected to the **Instructions** input of [GERTY Core](/en/core/gerty-core/).

</Steps>
