AccSet creates an ABB `AccSet` instruction that reduces the robot's acceleration and ramp values. It softens how the robot accelerates up to the programmed speed and how it decelerates when stopping, which lowers dynamic loads when handling fragile parts or moving near the workspace limits. The setting applies to the moves that follow it in the instruction list.

## How to use

<Steps>

1. Set **Acceleration(%)** and **Ramp(%)** in the **Acceleration Params** tab.
2. To soften the deceleration into fine targets separately, set **FinePointRamp(%)** too.
3. Put the **Instruction** output where it should take effect in the instruction list connected to the **Instructions** input of [GERTY Core](/en/core/gerty-core/).

</Steps>

## Notes

<Aside type="tip">
  Use it where dynamic loads must be lower, such as when handling fragile parts or near the workspace limits. Acceleration(%) cannot go below 20%, and Ramp(%) cannot go below 10%.
</Aside>
