A component that creates an ABB `WaitTime` instruction, which pauses robot motion for a set time (s). The wait time comes from the **Time(s)** input, and **In Position** decides whether counting starts only after the robot has stopped completely.

## How to use

<Steps>

1. Connect the wait time (seconds) to **Time(s)**.
2. Leave **In Position** on (default) to start counting only after the robot has stopped; turn it off to start as soon as the program pointer reaches the instruction.
3. Put the **Instruction** output at its place in the instruction list connected to the **Instructions** input of [GERTY Core](/en/core/gerty-core/).

</Steps>
