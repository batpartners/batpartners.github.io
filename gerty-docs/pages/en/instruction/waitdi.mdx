## How to use

<Steps>

1. Connect the name of the digital input signal to wait for to **Signal**.
2. Set the value to wait for with **Value** (WaitDI tab).
3. Put the **Instructions** output at its place in the instruction list connected to the **Instructions** input of [GERTY Core](/en/core/gerty-core/).

</Steps>
