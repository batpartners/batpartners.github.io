This is a component that switches an auxiliary axis to independent mode and moves it to a specified position within one revolution. It is generated using the IndRMove instruction, and after performing the task, it is necessary to initialize it back to normal mode using IndReset.

## How to use

<Steps>

1. Type the mechanical unit name (e.g. STN1) in **MechUnit** and pick the axis in **Target Axis**.
2. Set the target position **ToRelNum(°)**, the **Direction Policy**, **Speed(°/s)** and **Ramp(%)** in the **Settings** tab.
3. Put the **Instructions** output at its place in the instruction list connected to the **Instructions** input of [GERTY Core](/en/core/gerty-core/).

</Steps>

## Notes

<Aside type="caution">
  An axis moved in independent mode must be returned to normal mode with [IndReset](/en/instruction/indreset/) when the work is done.
</Aside>
