This is a component that initializes the position and rotation values of an auxiliary axis (IndReset). It is primarily used to initialize accumulated external axis angle values before executing motion instructions.

This page covers the Positional Reference form, which takes the reference position from the <strong>RobTarget</strong> input.

## How to use

<Steps>

1. Connect a [RobTarget](/en/datatype/robtarget/) holding the reference pose to **RobTarget**.
2. Type the mechanical unit name (e.g. STN1) in **MechUnit** and pick the axis in **Target Axis**.
3. Pick `Short`, `Fwd` or `Bwd` as the **Direction Policy** in the **Settings** tab.
4. Put the **Instructions** output at its place in the instruction list connected to the **Instructions** input of [GERTY Core](/en/core/gerty-core/).

</Steps>

## Notes

<Aside type="tip">
  Use it to return an axis put in independent mode by [IndRMove](/en/instruction/indrmove/) to normal mode, or to clear accumulated external-axis angles before motion.
</Aside>

<Aside type="caution">
  **RobTarget** and **RefNum(°)** cannot be used together.
</Aside>
