A component that creates an <code>IndReset</code> instruction, which resets the logical position of an external axis. An axis in independent mode is also returned to normal mode. It is mainly used to clear accumulated external-axis angles before motion instructions run.

This page covers the form selected with <strong>Use Positional Reference</strong> in the right-click menu, which takes the reference position from the <strong>RobTarget</strong> input.

## How to use

<Steps>

1. Connect a [RobTarget](/en/datatype/robtarget/) holding the reference pose to **RobTarget**.
2. Type the mechanical unit name (e.g. STN1) in **MechUnit** and pick the axis in **Target Axis**.
3. In the **Settings** tab, pick `Short (±180°)`, `Forward (+direction)` or `Backward (-direction)` in **Direction**.
4. Put the **Instruction** output at its place in the instruction list connected to the **Instructions** input of [GERTY Core](/en/core/gerty-core/).

</Steps>

## Notes

<Aside type="tip">
  Use it to return an axis put in independent mode by [IndRMove](/en/instruction/indrmove/) to normal mode, or to clear accumulated external-axis angles before motion.
</Aside>

<Aside type="caution">
  **RobTarget** and **RefNum(°)** cannot be used together. All axes must also be stationary before this instruction runs.
</Aside>
