This is a component that generates ActUnit/DeactUnit instructions to activate or deactivate a mechanical unit. It is used to switch the activation state of external axis equipment (such as positioners or tracks) during RAPID program execution.

## How to use

<Steps>

1. Type the mechanical unit name (e.g. STN1) in **MechUnit** ((De)ActUnit tab).
2. With **Activate** on you get `ActUnit` (activate); off gives `DeactUnit` (deactivate).
3. Put the **Instructions** output at its place in the instruction list connected to the **Instructions** input of [GERTY Core](/en/core/gerty-core/).

</Steps>
