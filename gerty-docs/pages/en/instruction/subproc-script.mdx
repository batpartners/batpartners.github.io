This component builds a RAPID sub-procedure and its call instructions from procedure code you write yourself. Use it to put PROC code in directly instead of an instruction list.

This page covers the form selected with **Script Mode** in the right-click menu. This form has no settings tab; the procedure name comes from the PROC declaration in **Proc Code**.

## How to use

<Steps>

1. Connect the RAPID code from PROC to ENDPROC to **Proc Code**.
2. Connect a call string (e.g. `CustomProc 5, target1;`) to **Call**, one per call site.
3. Put the **SubProc** output at its place in the instruction list connected to the **Instructions** input of [GERTY Core](/en/core/gerty-core/).

</Steps>

## Notes

<Aside type="caution">
  The procedure name and arguments in **Call** must match the PROC declaration in **Proc Code**.
</Aside>
