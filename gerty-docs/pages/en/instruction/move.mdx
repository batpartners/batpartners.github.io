A component that creates ABB move instructions (`MoveL`, `MoveJ`). It makes a move for each input RobTarget, with the motion type, speed and zone set once in the settings. Options can switch only the first and last targets to `MoveJ` or to zone `fine`.

## How to use

<Steps>

1. Connect the output of [RobTarget](/en/datatype/robtarget/) or [Positioner RobTarget](/en/datatype/positioner-robtarget-dynamic/) to **RobTargets**.
2. In the **Move** tab, pick the motion type, speed and zone with **Move**.
3. Turn on **MoveJ Start End** for `MoveJ` on the first and last targets only, and **Fine Start End** to stop exactly at them.
4. Put the **Instruction** output at its place in the instruction list connected to the **Instructions** input of [GERTY Core](/en/core/gerty-core/).

</Steps>
