A component that creates ABB Trigger Move instructions (`TriggLIOs`, `TriggJIOs`), which fire one or more I/O signals at set positions along the path while moving. It makes a trigger move for each input RobTarget and fires the I/O events bundled in [TriggIOs](/en/datatype/triggios/).

## How to use

<Steps>

1. Connect the output of [RobTarget](/en/datatype/robtarget/) or [Positioner RobTarget](/en/datatype/positioner-robtarget-dynamic/) to **RobTargets**.
2. Connect the [TriggIOs](/en/datatype/triggios/) output to **TriggIOs**; each trigger is defined with [IOEvent](/en/datatype/iodevent/).
3. In the **Trigger Move** tab, pick the motion type, speed and zone with **Trigger Move**.
4. Put the **Instruction** output at its place in the instruction list connected to the **Instructions** input of [GERTY Core](/en/core/gerty-core/).

</Steps>

## Notes

<Aside type="note">
  Picking `TriggLIOs` as the motion type gives a linear move, and `TriggJIOs` a joint move.
</Aside>
