## How to use

<Steps>

1. Connect the output of [RobTarget](/en/datatype/robtarget/) or [Positioner RobTarget](/en/datatype/positioner-robtarget/) to **RobTargets**.
2. Connect the output signal name to **Signal** and the value to write to **DO Value**.
3. Set the motion type, speed, zone and **MoveJ Start & End** / **Fine Start & End** in the **ABB MoveXO** tab.
4. Put the **Instructions** output at its place in the instruction list connected to the **Instructions** input of [GERTY Core](/en/core/gerty-core/).

</Steps>

## Notes

<Aside type="note">
  Depending on the signal type, the instruction is `MoveJDO` / `MoveLDO` (digital), `MoveJGO` / `MoveLGO` (group) or `MoveJAO` / `MoveLAO` (analog).
</Aside>
