A component that creates ABB move instructions (`MoveJDO`, `MoveLDO`, `MoveJGO`, `MoveLGO`, `MoveJAO`, `MoveLAO`) combined with a digital (DO), group (GO) or analog (AO) output signal. While moving to each target, it sets the value of the output signal named in **Signal**. The instruction is chosen as the motion type in **MoveOutput** in the settings.

## How to use

<Steps>

1. Connect the output of [RobTarget](/en/datatype/robtarget/) or [Positioner RobTarget](/en/datatype/positioner-robtarget-dynamic/) to **RobTargets**.
2. Connect the output signal name to **Signal** and the value to write to **DO Value**.
3. In the **ABB MoveOutput** tab, pick the motion type, speed and zone with **MoveOutput**, and set **MoveJ Start End** / **Fine Start End**.
4. Put the **Instruction** output at its place in the instruction list connected to the **Instructions** input of [GERTY Core](/en/core/gerty-core/).

</Steps>

## Notes

<Aside type="note">
  The motion type picked in **MoveOutput** decides whether the instruction is `MoveJDO` / `MoveLDO` (digital), `MoveJGO` / `MoveLGO` (group) or `MoveJAO` / `MoveLAO` (analog). Make sure the signal connected to **Signal** is of the matching kind.
</Aside>
