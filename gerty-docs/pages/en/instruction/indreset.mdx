This is a component that initializes the position and rotation values of an auxiliary axis (IndReset). It is primarily used to initialize accumulated external axis angle values before executing motion instructions.

## How to use

<Steps>

1. Type the mechanical unit name (e.g. STN1) in **MechUnit** and pick the axis in **Target Axis**.
2. Pick the **Direction Policy** in the **Settings** tab. For `Short` / `Fwd` / `Bwd`, also set the reference position **RefNum(°)**; `Old` keeps the current logical position.
3. Put the **Instructions** output at its place in the instruction list connected to the **Instructions** input of [GERTY Core](/en/core/gerty-core/).

</Steps>

## Notes

<Aside type="tip">
  Use it to return an axis put in independent mode by [IndRMove](/en/instruction/indrmove/) to normal mode, or to clear accumulated external-axis angles before motion.
</Aside>
