A component that creates an <code>IndReset</code> instruction, which resets the logical position of an external axis. An axis in independent mode is also returned to normal mode. It is mainly used to clear accumulated external-axis angles before motion instructions run.

This page covers the default **Use Numeric Reference** form from the right-click menu, which takes the reference position as a number in **RefNum(°)**.

## How to use

<Steps>

1. Type the mechanical unit name (e.g. STN1) in **MechUnit** and pick the axis in **Target Axis**.
2. In the **Settings** tab, set the reference position **RefNum(°)** and pick how the measurement system is aligned in **Direction**: `Short (±180°)`, `Forward (+direction)` or `Backward (-direction)`.
3. Put the **Instruction** output at its place in the instruction list connected to the **Instructions** input of [GERTY Core](/en/core/gerty-core/).

</Steps>

## Notes

<Aside type="tip">
  Use it to return an axis put in independent mode by [IndRMove](/en/instruction/indrmove/) to normal mode, or to clear accumulated external-axis angles before motion.
</Aside>

<Aside type="caution">
  All axes must be stationary before this instruction runs.
</Aside>
