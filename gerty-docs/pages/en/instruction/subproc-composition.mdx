## How to use

<Steps>

1. Connect the instruction list the procedure contains to **Instructions**.
2. Type the procedure name in **Procdure Name** (SubProcedure tab).
3. Put the **Sub Proc.** output at its place in the instruction list connected to the **Instructions** input of [GERTY Core](/en/core/gerty-core/).

</Steps>
