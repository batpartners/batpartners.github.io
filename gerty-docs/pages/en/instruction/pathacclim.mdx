PathAccLim creates an ABB `PathAccLim` instruction that sets or releases the TCP acceleration and deceleration limits along the motion path. Acceleration and deceleration can be switched on separately, and each limit that is on keeps the TCP below its maximum (m/s²). Turning both off releases the limits.

## How to use

<Steps>

1. Turn on the TCP acceleration / deceleration limits with **AccLim** / **DecelLim** (Acceleration Params tab).
2. Set the maximum for each limit that is on in **AccMax(m/s²)** / **DecelMax(m/s²)**.
3. Put the **Instruction** output at its place in the instruction list connected to the **Instructions** input of [GERTY Core](/en/core/gerty-core/).

</Steps>
