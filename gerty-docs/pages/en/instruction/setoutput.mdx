SetOutput generates `SetDO`, `SetGO` and `SetAO` instructions that change digital, group and analog output signal values. Pick the signal type in <strong>Signal Type</strong>. DO stands for Digital Output, GO for Group Output and AO for Analog Output.

## How to use

<Steps>

1. Connect the output signal name to **Signal**.
2. Pick the **Signal Type** in the **SetXO** tab; for a digital output, set the value with **DO Value**.
3. Put the **Instructions** output at its place in the instruction list connected to the **Instructions** input of [GERTY Core](/en/core/gerty-core/).

</Steps>
