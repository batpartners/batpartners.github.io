SetOutput creates a `SetDO`, `SetGO` or `SetAO` instruction that changes the value of a digital, group or analog output signal. Pick the signal type in <strong>Signal Type</strong> in the settings; the value control (<strong>DO Value</strong> / <strong>GO Value</strong> / <strong>AO Value</strong>) changes with the type. DO stands for Digital Output, GO for Group Output and AO for Analog Output.

## How to use

<Steps>

1. Connect the output signal name to **Signal**.
2. Pick the **Signal Type** in the **SetOutput** tab and set the value in the control that appears: **DO Value** for a digital output, **GO Value** for a group output, **AO Value** for an analog output.
3. Put the **Instruction** output at its place in the instruction list connected to the **Instructions** input of [GERTY Core](/en/core/gerty-core/).

</Steps>
