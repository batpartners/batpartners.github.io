This is a component that switches an auxiliary axis to independent mode and moves it to a specified position within one revolution. It is generated using the IndRMove instruction, and after performing the task, it is necessary to initialize it back to normal mode using IndReset.

This page covers the Positional Reference form, which takes the target position from the <strong>RobTarget</strong> input.

## How to use

<Steps>

1. Connect a [RobTarget](/en/datatype/robtarget/) holding the target pose to **RobTarget**; only the target axis component is used.
2. Type the mechanical unit name (e.g. STN1) in **MechUnit** and pick the axis in **Target Axis**.
3. Set the **Direction Policy**, **Speed(°/s)** and **Ramp(%)** in the **Settings** tab.
4. Put the **Instructions** output at its place in the instruction list connected to the **Instructions** input of [GERTY Core](/en/core/gerty-core/).

</Steps>

## Notes

<Aside type="caution">
  An axis moved in independent mode must be returned to normal mode with [IndReset](/en/instruction/indreset/) when the work is done.
</Aside>

<Aside type="note">
  For a robot axis, give the target position in **ToRelNum(°)** instead of **RobTarget**.
</Aside>
