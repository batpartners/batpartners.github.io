## How to use

<Steps>

1. Connect the **GERTY Robot** output of [ABB Robots](/en/robot-tool/abbrobot/) to **GERTY Robot**.
2. Connect the instruction list to **Instructions**; the list order is the robot execution order. Connect **SubProc.** if you use sub-procedures.
3. Connect the **GERTY Solver** output to [Display Solver](/en/core/display-solver/) and [Analysis Deconstructor](/en/core/analysis/), and the **GERTY Code** output to [Code Solver](/en/core/code-solver/).

</Steps>

## Notes

<Aside type="caution">
  The order of the **Instructions** list maps directly to the execution order, so sort it in the intended motion order.
</Aside>
