GERTY Core computes robot motion from the defined robot setup (Robot Setup) and instructions. It outputs **GERTY Solver** for simulation and analysis and **GERTY Code** for RAPID code generation: the base data required to run Display Solver and Code Solver.

## How to use

<Steps>

1. Connect the **Robot Setup** output of [ABB Robots](/en/robot-tool/abbrobot/) to **Robot Setup**.
2. Connect the instruction list to **Instructions**; the list order is the robot execution order. Connect **SubProc** if you use sub-procedures.
3. If needed, set **Config Option (Cfx = 1)** and **Ignore Errors** in the **GERTY Core** tab.
4. Connect the **GERTY Solver** output to [Display Solver](/en/core/display-solver/) and [Analysis Deconstructor](/en/core/analysis/), and the **GERTY Code** output to [Code Solver](/en/core/code-solver/).

</Steps>

## Notes

<Aside type="caution">
  The order of the **Instructions** list maps directly to the execution order, so sort it in the intended motion order.
</Aside>

<Aside type="caution">
  With **Ignore Errors** on, code is output even when motion errors are detected. Review the RAPID code and operating procedure before running it on the robot. With the default (off), code generation stops when errors are detected.
</Aside>
