Display Solver simulates and visualizes the defined robot motion in the Rhino viewport so you can review the whole process. It takes the result computed by GERTY Core, plays it from the simulation control window, and outputs the current TCP plane.

## How to use

<Steps>

1. Connect the **GERTY Solver** output of [GERTY Core](/en/core/gerty-core/) to **GERTY Solver**.
2. Turn on **Simulation Window** in the **Simulation** tab to open the simulation control window, and play the robot motion in the Rhino viewport from there.
3. If needed, use the **Current TCP** output for the current TCP plane.

</Steps>
