A component that generates a RAPID program from the defined robot motions and transfers and uploads it to a networked ABB controller.

This page covers <strong>[Single-Task (Standard)]</strong>, the default mode in the right-click menu, which exports the program as a single RAPID task. Multitasking programs with socket communication are made in <strong>[Multi-Task (Option 623-1)]</strong> mode.

## How to use

<Steps>

1. Connect the **GERTY Code** output of [GERTY Core](/en/core/gerty-core/) to **GERTY Code**. To load straight to a controller, connect the [Scan ABB Controller](/en/controller-utils/scanabbcontroller/) output to **ABB Controller**.
2. Set **Program Folder** and **Program Name** in the **Program Settings** tab.
3. Press **Export** in the **Export** tab to generate the RAPID code. With **Auto Load** on, the program is loaded to the connected controller afterwards. The result appears in **Export Log**.
4. Open the generated code with **Open in Editor** to check it.

</Steps>

## Notes

<Aside type="tip">
  **Open in Editor** opens the generated code in VSCode, or in Notepad if VSCode is not installed.
</Aside>

<Aside type="note">
  Change the save location with **Select a Local directory…** in the right-click menu and open it with **Open Local directory**. The default location is `Documents\GERTY\RobotPrograms`.
</Aside>
