A component that deconstructs the analysis data computed by GERTY Core into a readable text log. Along with the robot axis angles per target, it reports the indices and error types where robot-pose errors or reach issues occur.

## How to use

<Steps>

1. Connect the **GERTY Solver** output of [GERTY Core](/en/core/gerty-core/) to **GERTY Solver**.
2. Read the robot axis angles from **RobAx Angles**, and the failing indices and per-line error types from **Error Idx** and **Error Report**.

</Steps>
