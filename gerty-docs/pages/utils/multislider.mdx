## 사용 순서

<Steps>

1. **Multi Sliders** 탭에서 **Value01** 값을 정한다.
2. 값이 더 필요하면 컴포넌트를 우클릭해 **Add a new slider** 로 슬라이더를 추가한다. 추가한 슬라이더는 Value02, Value03 … 순서로 이어지며, **Remove the last slider** 로 마지막 슬라이더를 지운다.
3. **Values** 출력으로 모든 값을 순서대로 받는다.

</Steps>
