GERTY 를 설치하고 체험판을 쓰는 방법, 정식 라이선스를 신청하고 등록하는 순서를 설명한다. 각 단계의 번호는 바로 위 그림의 같은 번호를 가리킨다.

<DocTags tags={[{ text: "GERTY 소개", tone: "accent" }, { text: "설치" }, { text: "라이선스" }]} />

## 1. 설치와 체험판

<NumberedShot src="/assets/images/external/Package-Manager.png" alt="Rhino Package Manager" marks={[[2.5, 17.5], [84, 81.5], [2.5, 87.5]]} />

<MarkedSteps>

1. Rhino 에서 **PackageManager** 를 열고 검색창에 `GERTY` 를 입력한다.
2. 최신 버전을 고르고 **Install** 을 누른 뒤 Rhino 를 다시 실행한다.
3. **Automatically update packages when Rhino starts** 를 켜 두면 Rhino 를 켤 때마다 GERTY 가 최신 버전으로 자동 업데이트된다.

</MarkedSteps>

<Aside type="note">
  설치 후 처음 실행하면 체험판 라이선스(Trial License)가 자동으로 적용되어, 30일 동안 모든 기능을 사용할 수 있습니다.
</Aside>

## 2. 하드웨어 ID 확인 (Get HardwareIDs)

체험판 기간이 끝나면 유료 구독으로 정식 버전을 계속 쓸 수 있다. 라이선스를 신청하려면 먼저 이 PC 의 하드웨어 ID(MAC 주소 등)가 필요하다.

<NumberedShot src="/assets/images/external/Machine-ID.png" alt="Get HardwareIDs 와 출력 패널" marks={[[12, 16.2], [38.5, 5], [30, 46.2]]} />

<MarkedSteps>

1. Grasshopper 캔버스에 [Get HardwareIDs](/setup/gethardwareids/) 컴포넌트를 놓고, **MachineIDs** 출력에 Panel 을 연결한다.
2. 패널 위에서 마우스 오른쪽 버튼을 눌러 **Copy Data Only** 로 ID 를 복사한다.
3. **Contact Support** 를 눌러 열리는 라이선스 신청 양식에 복사한 ID 를 붙여 넣어 제출한다.

</MarkedSteps>

<Aside type="note">
  양식이 열리지 않거나 제대로 표시되지 않으면 기술 지원팀(contact@b-at.kr)으로 ID 를 보내 주시기 바랍니다.
</Aside>

## 3. 라이선스 등록 (Activate License)

정식 라이선스는 contact@b-at.kr 로 구매한다. 발급받은 라이선스 키는 아래 순서로 등록한다.

<NumberedShot src="/assets/images/external/License-Active.png" alt="Grasshopper 의 GERTY Ver.2 메뉴" marks={[[45, 4.5], [68, 19.4], [65.5, 53.6], [57.5, 74]]} />

<MarkedSteps>

1. Grasshopper 리본에서 **GERTY Ver.2** 메뉴를 연다.
2. **Activate GERTY License** 에 라이선스 키를 입력하고, Rhino 를 완전히 종료한 뒤 다시 실행한다.
3. 같은 메뉴에서 라이선스 상태(User / Trial)와 남은 기간을 언제든 확인할 수 있다.
4. **Templates** 에서 GERTY 전용 템플릿을 열어 바로 프로젝트를 시작한다.

</MarkedSteps>
