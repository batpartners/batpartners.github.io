GERTY 는 로봇암 기반 맞춤형 가공의 프로그래밍을 돕는 CAM 소프트웨어다. 이 페이지는 GERTY 소개와 함께, 모든 컴포넌트에 공통인 화면 구성과 조작 방법을 다룬다.

## 1. GERTY 란?

<NumberedShot src="/assets/images/30.jpg" alt="GERTY" width={440} marks={[]} />

GERTY 는 Rhino–Grasshopper 환경에서 작동하는 소프트웨어 프레임워크다. 로봇암과 부가축 제원에 맞는 적층·절삭 가공 경로의 계획과 생성, 3차원 동작 시뮬레이션, 로봇 제어 프로그램 작성까지 다루는, 비에이티 파트너스의 로봇 기반 맞춤형 제조 하드웨어 시스템을 위한 오프라인 프로그래밍(OLP) 솔루션이다.

CAD 데이터를 바탕으로 로봇 가공 동작을 직관적으로 최적화할 수 있다. Grasshopper 의 비주얼 프로그래밍 인터페이스를 쓰므로, 코딩 없이도 맞춤형 가공 경로를 쉽게 만들 수 있다.

현재 ABB 다축 로봇암과 부가축을 모두 지원하며, Kuka, Fanuc, Hyundai, Universal Robots, Yaskawa 등 여러 산업용·협동 로봇 제조사 제품으로 호환 범위를 넓히고 있다.

## 2. 컴포넌트 구성

GERTY 컴포넌트는 Grasshopper 컴포넌트와 같은 구조를 따른다. 입력을 연결하고 GERTY UI 에서 설정을 고르면, 결과가 출력으로 전달된다.

<NumberedShot src="/assets/images/Component_2026.png" alt="GERTY 컴포넌트의 INPUT, ICON, OUTPUT, GERTY UI" width={420} marks={[]} />

| 부분 | 하는 일 |
| --- | --- |
| **INPUT** | Rhino·GERTY 컴포넌트를 연결하거나 값을 직접 넣는다. |
| **ICON** | 오른쪽 클릭하면 컨텍스트 메뉴가 열린다(모드 전환 등). |
| **OUTPUT** | 계산 결과를 다음 컴포넌트로 넘긴다. |
| **GERTY UI** | 컴포넌트 아래쪽의 설정 영역. 탭으로 나뉘어 있다. |

## 3. 입력 (Input)

반드시 넣어야 하는 값과, 비워 둘 수 있는 선택 값(Optional)이 있다.

<Aside type="note">
  선택 값은 비워 두어도 됩니다. 필요한 값이 모두 들어가면 컴포넌트가 회색으로 표시되며, 이것이 정상 상태입니다.
</Aside>

## 4. GERTY UI

컴포넌트 아래쪽의 설정 영역이다. 항목마다 GERTY 기본값이 있고, 사용자가 바꿀 수 있다. Grasshopper 의 Text, Slider, Button, Toggle, DropDown, Panel, Color 와 같은 요소를 기능별 탭(Tab)으로 묶어 보여 준다.

### 탭 (Tab)

기능별 설정을 탭으로 묶었다. 고른 탭은 어둡게 활성화되고, 그 안의 설정을 바꿀 수 있다. 바꾸지 않은 필수 값은 GERTY 기본값을 따른다. 큰 기능은 세로 탭, 세부 기능은 가로 탭으로 나뉘며, 탭을 오가며 값을 설정한다.
