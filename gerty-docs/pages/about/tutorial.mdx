## 2. 템플릿 열기

<MarkedSteps>

1. Grasshopper 상단 메뉴에서 **GERTY Ver.2** 를 연다.

3. 하위 메뉴에서 원하는 유형(Basic, Drawing, Hot-wire Cutting, Milling, 3D Printing, Block Laying, WAAM)을 고르면 예제 정의가 캔버스에 열린다.

</MarkedSteps>

## 4. 내 작업에 적용하기

<Steps>

1. 내 작업과 가장 비슷한 템플릿을 열고, 시뮬레이션을 한 번 돌려 전체 동작을 확인한다.
2. **로봇 셋업** 단계의 로봇, 툴, 작업 좌표계를 내 셀에 맞게 바꾼다([ABB Robots](/robot-tool/abbrobot/), [ToolData](/datatype/tooldata/), [WobjData](/datatype/wobjdata/)).
3. 템플릿의 예제 형상을 내 형상으로 바꾸고, **경로 만들기** 단계의 설정(간격, 레이어 높이 등)을 조정한다.
4. [Display Solver](/core/display-solver/) 로 도달 범위와 충돌을 확인한 뒤, [Code Solver](/core/code-solver/) 로 RAPID 코드를 만든다.

</Steps>
