## 사용 순서

<Steps>

1. **Positioner** 에 [ABB Positioner](/robot-tool/positioner/) 컴포넌트 데이터를 연결한다.
2. **Target Planes** 에 타겟 평면을, **Target Base** 에 그 평면이 정의된 기준 평면을 연결한다.
3. **Reference Plane** 에 Static 모드에서 포지셔너 방향(Orientation)의 기준이 되는 평면을 연결한다.
4. **RobTargets** 출력을 이동 명령에 연결한다. 시작·끝 타겟을 따로 쓰려면 **Output** 탭의 **Split Start / Split End** 를 켠다.

</Steps>

## 주의 사항

<Aside type="tip">
  **Split Start / Split End** 는 Target Plane 의 브랜치(Branch)마다 첫 번째·마지막 인덱스를 분리해 **Start Targets / End Targets** 로 출력한다.
</Aside>
