## 사용 순서

<Steps>

1. **Signal** 에 출력 신호의 이름을 연결한다.
2. **IO Event** 탭에서 **Signal Type**(Digital / Group / Analog Output)을 고르고, 그에 맞게 바뀌는 값 입력 칸(**DO Value** / **GO Value** / **AO Value**)에 출력할 값을 정한다.
3. **Settings** 탭에서 트리거 위치를 정한다. **Start** 로 거리의 기준점(이동 시작점 / 종료점)을, **Distance** 로 그 기준점에서의 거리(mm)를, **EquipLag(s)** 로 외부 장비의 응답 지연 보상값을 넣는다. 이벤트를 잠시 끄려면 **Used** 를 해제한다.
4. 여러 IOEvent 의 **IOEvent** 출력을 [TriggIOs](/datatype/triggios/) 의 **IOEvent** 입력에 묶어 연결한다.

</Steps>

## 주의 사항

<Aside type="tip">
  **EquipLag(s)** 가 양수(+)이면 지정 위치에 닿기 전에 신호를 미리 내보내고, 음수(-)이면 지정 위치를 지난 뒤에 내보냅니다.
</Aside>
