## 사용 순서

<Steps>

1. **Signal** 에 신호 데이터를 연결한다.
2. **IOData Signal** 탭에서 **Signal Type**(디지털 / 그룹 / 아날로그)과 **DO Value** 를 정한다.
3. **Settings** 탭에서 트리거 위치를 정한다. **Start** 로 거리의 기준점(이동 시작점 / 종료점)을, **Distance(mm)** 로 그 기준점에서의 거리를, **EquipLag(sec.)** 로 외부 장비의 응답 지연 보상값을 넣는다.
4. 여러 IOEvent 의 **IO Data** 출력을 [TriggIOs](/datatype/triggios/) 의 **IOs** 입력에 묶어 연결한다.

</Steps>

## 주의 사항

<Aside type="tip">
  **EquipLag(sec.)** 가 양수(+)이면 지정 위치에 닿기 전에 신호를 미리 내보내고, 음수(-)이면 지정 위치를 지난 뒤에 내보낸다.
</Aside>
