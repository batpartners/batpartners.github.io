## 사용 순서

<Steps>

1. **Weld Sched** 에 용접 프로그램 번호(스케줄)와 용접 모드를, **Weighting** 에 wirefeed1 가중치를 연결한다. 위빙이 필요하면 [WeaveData](/datatype/weavedata/) 도 연결한다.
2. **WeldData** 탭의 **Name** 에 변수명을 쓴다.
3. **Weld ArcData** 탭에서 전압·와이어 송급·제어·전류를, **Weld Param** 탭에서 **Weld Speed(mm/s)** 를 정한다.
4. **WeldData** 출력을 [ArcMove](/instruction/arcmove/) 의 **WeldData** 입력에 연결한다.

</Steps>
