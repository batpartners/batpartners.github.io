## 사용 순서

<Steps>

1. **Weaving Shape** 로 위빙 패턴(지그재그, V형, 삼각형, 원형)을, **Weaving Type** 으로 축 제어 방식을 고른다.
2. **Length(mm) / Width(mm) / Height(mm)** 로 패턴의 크기를 정한다.
3. **WeaveData** 출력을 [WeldData](/datatype/welddata/) 의 **WeaveData** 입력에 연결한다.

</Steps>

## 주의 사항

<Aside type="note">
  **Height(mm)** 는 V형과 삼각형 패턴에서만 쓰이고, 지그재그와 원형에서는 무시됩니다.
</Aside>

<Aside type="note">
  **Length(mm)** 의 의미는 Weaving Type 에 따라 다릅니다. Rapid1/Rapid2 에서는 위빙 주파수(Hz), 원형 패턴에서는 패턴 간격입니다.
</Aside>
