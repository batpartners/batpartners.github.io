## 사용 순서

<Steps>

1. **Brep** 에 정삭할 서피스(Brep 또는 Surface)를, **Reference Plane** 에 경로 기준 평면을 연결한다.
2. **Settings** 탭에서 UV 진행 방향(**UV Direction**), 경로 간격(**Stepover(mm)**), 표면 법선 쪽 기울기(**Tilting Weight**), **Tolerance** 를 정한다.
3. **Target Planes** 출력을 [RobTarget](/datatype/robtarget/) 의 **Target Plane** 입력에 연결해 로봇 타겟으로 만든다.

</Steps>
