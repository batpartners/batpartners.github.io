룰드 서피스로부터 열선 절단용 경로를 생성하는 컴포넌트이다. 사용자는 타겟 평면을 생성할 포인트 개수와, 룰드 서피스 내부 파라미터 값(기본 : 0.5), 선택 옵션으로 열선 툴을 부드럽게 조정할 수 있는 어트랙터 값을 설정한다. 이외의 열선 경로 방향, 툴 방향, 진입 간격의 세부 설정이 가능하다.

## 사용 순서

<Steps>

1. **Surface** 에 룰드 서피스를 연결한다.
2. **Target Count** 로 타겟 개수를 정한다. 필요하면 **Parameter**(기본값 0.5)로 타겟 원점 위치를, **Wrist Object** 로 툴 방향을 부드럽게 끌어 줄 어트랙터를 넣는다.
3. **Settings** 탭에서 절단 방향(**Cutting Dir. Flip**), 툴 방향(**Tool Flip**), UV 방향(**UV Flip**), 시작·끝 연장(**Extension(mm)**)을 정한다.
4. **Target Planes** 출력을 [RobTarget](/datatype/robtarget/) 의 **Target Plane** 입력에 연결해 로봇 타겟으로 만든다.

</Steps>

## 주의 사항

<Aside type="note">
  **UV Flip** 은 U·V 양방향이 모두 1차(degree 1)인 룰드 서피스에서만 작동합니다.
</Aside>
