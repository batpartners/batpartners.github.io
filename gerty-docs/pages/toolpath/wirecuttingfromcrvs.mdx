**WireCutting** 컴포넌트의 우클릭 메뉴 기본 모드인 **From Curves** 를 설명한다. 두 레일 커브(**Rail A**, **Rail B**)로부터 열선 절단용 툴패스를 생성하며, 두 레일이 정의하는 룰드 서피스의 Span 을 따라 **Spacing** 간격으로 타겟 평면을 만든다. 선택 입력 **Wrist** 에 Point 또는 Curve 를 연결하면 타겟 Z 방향을 그쪽으로 지향시킨다. 설정은 **Cutting**(타겟 간격·원점 파라미터), **Path**(절단 방향·툴 방향·연장), **Wrist**(Wrist 배분), **Preview** 탭으로 나뉜다. 룰드 서피스를 입력으로 쓰는 **From Surface** 모드는 [WireCutting (From Surface)](/toolpath/wirecuttingfromsrf/) 페이지에서 따로 다룬다.

## 사용 순서

<Steps>

1. 컴포넌트 우클릭 메뉴에서 **From Curves** 가 선택되어 있는지 확인한다 (기본값).
2. **Rail A**, **Rail B** 에 룰드 서피스를 정의할 두 레일 커브를 연결한다. 커브 리스트를 연결하면 인덱스 순서로 쌍을 이루고, 쌍마다 출력의 가지(branch)가 하나씩 만들어진다.
3. **Cutting** 탭에서 타겟 간격(**Spacing**, mm)과 Span 위의 원점 위치(**Parameter**, 기본값 0.5)를 정한다.
4. **Path** 탭에서 절단 방향(**Dir Flip**), 툴 방향(**Tool Flip**), 시작·끝 연장(**Extension**, mm)을 정한다.
5. 툴 방향(타겟 Z)을 지향시키려면 **Wrist** 에 Point 또는 Curve 를 연결하고, **Wrist** 탭에서 배분 방식(**Wrist Mode**)과 Sweep 가이드 형태(**Wrist Blend**)를 정한다.
6. **Target Planes** 출력을 [RobTarget](/datatype/robtarget/) 의 **Target Plane** 입력에 연결해 로봇 타겟으로 만든다.

</Steps>

## 주의 사항

<Aside type="note">
  우클릭 메뉴의 **Use Variable Parameters** 를 켜면 **Parameter** 입력이 추가되고 **Cutting** 탭의 **Parameter** 슬라이더는 숨겨집니다. 이 입력에는 0.0–1.0 숫자 리스트(절단 진행 방향으로 고르게 놓이는 샘플이며, 사이는 선형 보간합니다) 또는 가이드 커브(Span 마다 커브에 가장 가까운 점이 원점이 됩니다)를 연결합니다. 이 옵션은 별도 페이지가 없습니다.
</Aside>
