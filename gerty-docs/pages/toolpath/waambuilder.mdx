## 사용 순서

<Steps>

1. **Deposition ToolPaths** 에 슬라이서([Solid Shell](/toolpath/solidshell/), [Surface Shell](/toolpath/surfaceshell/), [Solid Fill](/toolpath/solidfill/) 등)의 출력을 연결한다. 첫 파트(최하단 파티션) 여부는 슬라이서가 경로에 담아 보내므로 따로 연결할 필요가 없다.
2. **Settings** 탭에서 채움을 먼저 쌓을지(**Infill first**), 여러 오브젝트를 레이어 단위로 쌓을지 오브젝트 단위로 쌓을지(**Layer by Layer**), 첫 파트 구분을 무시할지(**Ignore First Part**) 정한다.
3. **Preview** 탭의 **Layer Preview** 로 레이어별 적층 순서를 확인한다.
4. 레이어 종류별 출력(**First Shells** / **First Infills**, **Upper Shells** / **Upper Infills**, **Tween Shells**)을 각각 [RobTarget](/datatype/robtarget/) 으로 만들어 인스트럭션에 연결한다.

</Steps>

## 주의 사항

<Aside type="note">
  입력 경로가 첫 파트가 아니거나 **Ignore First Part** 가 TRUE 이면 **First Shells**, **First Infills** 는 출력되지 않습니다.
</Aside>
