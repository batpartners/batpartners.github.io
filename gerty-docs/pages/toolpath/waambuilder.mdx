## 사용 순서

<Steps>

1. **Deposition ToolPaths** 에 슬라이서([Solid Shell](/toolpath/solidshell/), [Surface Shell](/toolpath/surfaceshell/), [Solid Fill](/toolpath/solidfill/) 등)의 출력을, **Is Bottommost** 에 Solid Shell / Surface Shell 의 **Is Bottommost** 출력을 연결한다.
2. **Settings** 탭에서 채움을 먼저 쌓을지(**Infill first**), 여러 오브젝트를 레이어 단위로 쌓을지(**Layer by Layer**) 정한다.
3. **Preview** 탭의 **Layer Preview** 로 레이어별 적층 순서를 확인한다.
4. 레이어 종류별 출력(첫 레이어 Shell / Infill, 이후 레이어 Shell / Infill, Tween Shell)을 각각 [RobTarget](/datatype/robtarget/) 으로 만들어 인스트럭션에 연결한다.

</Steps>

## 주의 사항

<Aside type="note">
  **Is Bottommost** 가 FALSE 이면 **1st Shell Layers**, **1st Infill Layers** 는 출력되지 않는다.
</Aside>
