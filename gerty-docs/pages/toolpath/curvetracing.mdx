Curve Tracing 은 입력 커브를 따라가는(트레이싱하는) 로봇 툴패스를 생성하는 컴포넌트이다. **Resolution** 탭에서 경로의 정밀도를, **Tilting** 탭에서 TCP 를 기울이는 방향과 정도를 설정한다.

## 사용 순서

<Steps>

1. **Curves** 에 따라갈 커브를, **Reference Plane** 에 툴패스 기준 평면을 연결한다.
2. **Resolution** 탭에서 **Tolerance** 와 세그먼트 길이(**Min Edge** / **Max Edge**)를 정한다.
3. **Tilting** 탭에서 기울일 방향(**Tilt Target**)과 정도(**Tilt Weight**)를 정한다.
4. **Target Planes** 출력을 [RobTarget](/datatype/robtarget/) 의 **Target Plane** 입력에 연결해 로봇 타겟으로 만든다.

</Steps>

## 주의 사항

<Aside type="note">
  **Tilt Weight** 가 0.0 이면 TCP 는 **Reference Plane** 의 Z 방향을, 1.0 이면 **Tilt Target** 이 정한 방향(표면 법선 또는 커브 접선)을 따릅니다.
</Aside>
