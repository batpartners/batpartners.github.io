## 사용 순서

<Steps>

1. **Curves** 에 따라갈 커브를, **Reference Plane** 에 툴패스 기준 평면을 연결한다. TCP 를 표면 법선 쪽으로 기울이려면 **Geometry** 도 연결한다.
2. **Settings** 탭에서 **Tolerance**, 세그먼트 길이(**MinEdge / MaxEdge(mm)**), 기울기(**Tilting Weight**)를 정한다.
3. **Target Planes** 출력을 [RobTarget](/datatype/robtarget/) 의 **Target Plane** 입력에 연결해 로봇 타겟으로 만든다.

</Steps>

## 주의 사항

<Aside type="note">
  **Tilting Weight** 가 0.0 이면 TCP 는 **Reference Plane** 의 Z 방향을, 1.0 이면 Geometry 표면 법선(또는 커브 접선) 방향을 따른다.
</Aside>
