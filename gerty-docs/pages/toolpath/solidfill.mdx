## 사용 순서

<Steps>

1. **GERTYShellData** 에 [Solid Shell](/toolpath/solidshell/) 의 **GERTYShellData** 출력을 연결한다.
2. **Pattern** 탭에서 내부·외부 채움 패턴(**Int-Infill / Ext-Infill Type**)과 회전 각도(**Rotation(°)**)를 고른다.
3. **Infill** 탭에서 상·하단 솔리드 레이어 수, 외곽과 채움 사이 간격(**Layer Gap(mm)**), 내부 채움 밀도(**Int-Infill Amount**)를 정한다.
4. **Deposition ToolPaths** 출력을 [Deposition Builder](/toolpath/depositionbuilder/) 또는 [WAAM Builder](/toolpath/waambuilder/) 에 연결한다.

</Steps>
