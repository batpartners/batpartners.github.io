## 사용 순서

<Steps>

1. **Base Plane** 에 공급부 기준 평면을, **Unit Block** 에 단위 블록을, **Block Count** 에 [Block Designer](/toolpath/block-designer/) 의 **Block Count** 출력을 연결한다.
2. **Spacing** 탭에서 X·Y·Z 간격을, **Count** 탭에서 X·Y·Z 방향 개수를 정한다.
3. **Target Planes** 출력을 [RobTarget](/datatype/robtarget/) 의 **Target Plane** 입력에 연결해 로봇 타겟으로 만든다.

</Steps>

## 주의 사항

<Aside type="caution">
  **Block Count** 가 배치 가능 개수(X×Y×Z)보다 많으면 같은 배열에 겹쳐 반복 배치됩니다. **Count** 탭의 개수를 충분히 잡아 주십시오.
</Aside>
