## 사용 순서

<Steps>

1. **Target Planes0**, **Target Planes1** 에 타겟 평면 DataTree 를 하나씩 연결한다. 경로 묶음이 더 있으면 **+ ADD** 로 입력을 늘린다.
2. **Basic** 탭의 **Approaching Dir. / Leaving Dir.** 에서 진입·진출 방향(모션 방향 또는 타겟 평면의 축)을 고른다.
3. **Basic** 탭에서 진입·진출 거리(**Approaching / Leaving Dist.(mm)**)와 전이 경로의 타겟 개수(**Target Count**)를 정한다.
4. **Advanced** 탭에서 블렌드 연속성(**Continuity Type**)과 시작·끝의 불룩함(**Bulge Start / Bulge End**)을 조정한다.
5. **Fly-by Targets** 출력을 [RobTarget](/datatype/robtarget/) 의 **Target Plane** 입력에 연결해 로봇 타겟으로 만든다.

</Steps>
